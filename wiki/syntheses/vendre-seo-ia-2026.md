# Comment vendre du SEO IA en 2026

**Deuxième synthèse** de cette KB. ## 7 principes de vente SEO IA

### 1. Bannir le mot "visibilité"

Le mot "visibilité" évoque les réseaux sociaux dans la tête des clients. Il ne communique ni valeur business ni ROI. Remplacer systématiquement par :
- **"Mots-clés business"** — requêtes qui génèrent des leads/ventes
- **"Conversion"** — visiteur → client
- **"Leads qualifiés"** — trafic à intention transactionnelle

Source : Tim le répète dans les calls 3, 5, 6. Cécile et Dev web confirment que leurs clients "ne comprennent pas ce que visibilité veut dire".

### 2. Donner la data AVANT la signature

Le closing passe de 10% à 50% quand le consultant montre au prospect :
- Les mots-clés business qu'il va attaquer (avec volume et CPC)
- La roadmap des 3 premiers mois
- Les positions actuelles vs potentielles

Pas de "visibilité" abstraite. De la data concrète sur laquelle le prospect peut se projeter. Cf. [[concepts/data-proprietaire]].

### 3. La règle 80/20 du contenu

Ce qui ranke en 2026 : **80% consensus + 20% data propriétaire**. Le consensus (ce que tout le monde dit) est nécessaire mais insuffisant. Les 20% qui font la différence :
- Calls clients (verbatims, jargon sectoriel)
- Avis clients (formulations, pain points)
- Data interne (chiffres, cas d'usage, résultats)
- Études/sources que les concurrents n'ont pas

Cf. [[concepts/surprise-gap]], [[concepts/information-gain]], [[concepts/data-proprietaire]].

### 4. Le prix n'est jamais le frein — c'est le temps

Sur 10 prospects, aucun n'a bloqué sur le prix (590€). Les objections réelles :
- "J'ai pas le temps" (Juliette, Dev web, Julien, Franck)
- "Ça change tout le temps" (Christophe, Julien)
- "Je suis pas assez technique" (Cécile)

Réponse systématique : 3h/semaine intégrées dans le travail client, pas du temps en plus. ROI : 1 client signé = bootcamp amorti.

### 5. Le call EST le canal de conversion

Pas de tunnel de vente complexe. Pas de webinaire. Pas de page de vente longue. Le parcours :
1. Newsletter Algorithme (confiance sur plusieurs mois)
2. Call découverte (15-30 min, data + stats)
3. Email récap + lien Stripe
4. Décision rapide

Le call doit montrer : les stats réelles, le 80/20, l'annulation sans frais, le positionnement freelance (pair, pas formateur).

### 6. Les prospects ont déjà testé l'IA — et vu les limites

10/10 utilisent déjà l'IA. 0/10 ont un process structuré. Ils savent que l'IA peut faire plus mais ne savent pas comment. Le pitch n'est pas "découvrez l'IA" mais "structurez votre IA".

Le consultant doit montrer la plus-value humaine : "L'IA fait 80%, moi je fais les 20% que l'IA ne peut pas faire" (réflexion, data propriétaire, stratégie business).

### 7. Vendre un système, pas une formation

Le mot "formation" repousse les praticiens expérimentés (Franck 15 ans, Jamel 10 ans, Christophe 30 ans). Dire :
- **"Système SEO IA"** ✓
- **"Workflow propriétaire"** ✓
- **"Second cerveau"** ✓
- ~~"Formation SEO"~~ ✗
- ~~"Cours"~~ ✗
- ~~"Apprentissage"~~ ✗
