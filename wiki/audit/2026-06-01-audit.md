### Problèmes et actions

1. **probe2 — job mort.** Pointait vers `/tmp/probe2.sh` (inexistant), reliquat de debug du 4 mai. → ✅ FAIT : déchargé + plist supprimé.

2. **revue-presse — plus aucun déclencheur.** Le cron GitHub Actions est commenté volontairement (GH Actions exige une `ANTHROPIC_API_KEY` non dispo, le job a été migré vers launchd local), MAIS le plist local était `.disabled` depuis le 4 mai. Résultat : la revue ne tournait plus qu'en manuel. → ✅ FAIT : plist local réactivé (`.disabled` → `.plist` + `launchctl load`), tous les jours 9h, via `run-revue-presse.sh` (auth Claude Code locale, pas de clé API requise). **À noter** : si tu préfères piloter la revue uniquement via `/agent-synthetic` (boucle apprenante), il suffit de redécharger ce plist.

3. **recap-jour — exit 1.** Le stderr historique mentionnait l'ancien chemin `~/Documents/seo-kb` mais c'était **périmé** : le wrapper actuel (`~/.local/bin/seo-kb/run-recap-jour.sh`) pointe déjà vers `~/Code/seo-kb`. La vraie cause d'échec est une **erreur de connexion API** (`ECONNRESET`) au run de 23h. Pas de fix chemin nécessaire.

4. **gsc-pull + ingest-backlog — exit 1 (erreur API).** `The socket connection was closed unexpectedly` sur les runs de ce matin (7h-8h). Le script `gsc-fetch.py` sort 0, c'est l'appel `claude` headless qui échoue. gsc-pull signale aussi l'absence du service account GSC (`~/.config/seo-kb/gsc-service-account.json`) mais c'est documenté et volontaire (mode dépôt manuel).

5. **Pattern API à investiguer (NON corrigé, à voir avec Tim).** 3 jobs (gsc-pull 7h, ingest-backlog 8h, recap-jour 23h) échouent sur des erreurs réseau/connexion API (`socket closed`, `ECONNRESET`) dans le contexte launchd. Probablement transitoire (réseau au réveil) ou contention si plusieurs jobs appellent l'API en même temps. **Reco** : ajouter un retry/backoff dans les wrappers qui appellent `claude` (3 tentatives, sleep progressif). À faire ensemble pour ne pas toucher aux wrappers canoniques sans validation.

6. **Mémoire désynchronisée.** `automation_revue_presse_todo` (snapshot du 2026-05-02) décrit une stack « GH Actions + slash commands » qui ne correspond plus à la réalité (11 launchd installés depuis). À réécrire (note auto-gérée, slug-sensible : ne pas éditer le snapshot, éditer la mémoire source).
