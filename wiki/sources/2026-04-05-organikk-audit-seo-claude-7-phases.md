# Audit SEO avec Claude : le workflow en 7 phases

**Auteur** : Timothée Boussardon (organikk.co/blog)
**Type** : article
**URL** : https://organikk.co/blog/audit-seo-claude
**Date publication** : 2026-04-05

## Contexte
Méthodologie d'audit SEO en 7 phases avec Claude Pro (20€/mois) et la seule data Google Search Console, sans outil tiers payant. L'angle : un audit utile est de la stratégie raisonnée sur la data client, pas une checklist technique crachée par un SaaS.

## Chiffres / faits clés
- Coût de l'outillage : 20€/mois (Claude Pro), zéro outil tiers payant.
- Durée d'audit : 4-6 heures en suivant toutes les phases.
- Historique GSC recommandé : minimum 16 mois pour la comparaison année sur année.
- Phase 1 (quick wins) cible les pages en position 3-12 sous-performantes.
- Plan d'action consolidé sur 3 horizons : semaines 1-2, mois 1, mois 2-3.

## Les 7 phases
- Phase 0 : audit positionnel (data GSC, mots-clés business, types de SERP)
- Phase 1 : quick wins (pages position 3-12)
- Phase 2 : cannibalisation (URLs en compétition sur la même requête)
- Phase 3 : architecture de cluster AEO (univers sémantique, gaps de contenu)
- Phase 4 : analyse vectorielle (entités manquantes, complétude sémantique)
- Phase 5 : audit du maillage interne (hiérarchie, structure)
- Phase 6 : briefs de contenu priorisés avec check anti-AI writing
- Phase 7 : plan d'action consolidé sur 3 horizons temporels

## Citations marquantes
> "Un audit SEO utile ne sort pas d'un outil payant qui crache une analyse générique." (attribution : Tim, 2026-04-05)

> "Le vrai goulot d'étranglement, c'est ta capacité à formuler des hypothèses business." (attribution : Tim, 2026-04-05)

## Angle SEO à retenir
- La contrainte limitante d'un audit n'est pas l'outil mais la capacité à poser des hypothèses business sur la data.
- L'audit raisonne sur la data du client : stratégie, pas diagnostic technique de conformité.

## Limites
Scrape public complet, pas de paywall. Les 7 phases recoupent les skills SEO propriétaires du vault.
