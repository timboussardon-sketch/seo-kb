# Agents SEO : les nouveaux outils des consultants

**Newsletter** : Algorithme #5 · **Date** : 13 mars 2026 · **Auteur** : Tim

## Données clés

### GEO = optimisation des basiques (étude arxiv 2602.12187)
- Optimiser la structure Hn seule → **+22 % hit rate** en phase retrieval
- Placer la réponse directe **dans les premiers paragraphes** → scores plus élevés. La repousser en bas → chute.
- Chaque affirmation doit être **auto-suffisante** : l'IA doit pouvoir la citer sans contexte autour → résonne avec le concept d'"atomes" de [[concepts/information-gain]]

### GSC : filtre requêtes de marque
- Google déploie un filtre brand / non-brand dans Google Search Console pour tous les sites éligibles
- Le trafic brand peut représenter **40 à 90 %** du trafic total → les agences ne peuvent plus se cacher derrière

### Agents SEO comme outils principaux
- Passage chatbot → **agents personnels, dédiés, thématisés**
- "Vous ne payerez pas un agent pour ce qu'il sait faire, mais pour ce qu'il **sait**" → [[concepts/data-proprietaire]] = le moat
- Agent SEO = 0 hallucination (contexte fermé), apprend de ses erreurs, génère des tâches 24/7

## Apports à la KB

- L'étude GEO arxiv:2602.12187 confirme que la structure (Hn, placement de la réponse) compte autant que le contenu pour être cité → renforce [[concepts/grounding-score]] (pas juste le vecteur contenu, aussi la structure)
- Les agents SEO incarnent le pattern [[concepts/persistent-wiki-vs-rag]] appliqué au consulting : contexte qui se nourrit avec le temps
