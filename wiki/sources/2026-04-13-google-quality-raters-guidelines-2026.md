# Google Quality Raters Guidelines — Édition 2026

**Auteurs** : Google Search Quality Team
**Type** : documentation publique Google (`source_type: doc-google`)
**Fichier raw** : `raw/papers/google-quality-raters-guidelines-2026.md`
**Date** : 2026 (édition mise à jour)
**Lien** : guidelines.raterhub.com (Search Quality Evaluator Guidelines)

## Contexte

Document normatif officiel Google. Définit ce que les évaluateurs humains (Quality Raters) considèrent comme du contenu de qualité. Ces évaluations alimentent l'entraînement des algorithmes de ranking — d'où sa valeur **doctrinale** pour le SEO. Édition 2026 : ajoute la pénalisation explicite du contenu "sans effort" (page 42).

## Méthode

Pas une étude empirique : un guide d'évaluation. Définit les échelles (Needs Met Rating), les piliers (E-E-A-T), les exemples concrets de contenu acceptable / pénalisé. C'est la **règle du jeu** côté Google, pas une mesure de marché.

## Chiffres clés

- **Page 42** : contenu "effort-less" → note la plus basse de l'échelle
- **4 piliers E-E-A-T** : Experience, Expertise, Authoritativeness, Trustworthiness
- **Échelle Needs Met** : Fully Meets > Highly Meets > Moderately Meets > Slightly Meets > Fails to Meet

## Résumé structuré

### Page 42 — Effort-less = note minimale

Cible explicite : contenu produit sans effort visible (typiquement IA non supervisée, scraping, contenu fin sans valeur ajoutée). Confirmation normative que le contenu IA pur sera pénalisé dès qu'un Quality Rater le voit. Connecte directement à [[concepts/anti-ai-writing]] (Wikipedia Signs + règles Tim).

### E-E-A-T — Les 4 piliers

- **Experience** : preuve d'usage / pratique réelle. Justifie [[concepts/data-proprietaire]] comme moat (pas juste un argument marketing — c'est dans la grille d'évaluation).
- **Expertise** : compétence technique démontrée
- **Authoritativeness** : reconnaissance externe (backlinks, mentions, profils LinkedIn / Wikipedia)
- **Trustworthiness** : transparence (auteur, sources, dates, contradictions assumées)

Cf. [[concepts/e-e-a-t]] (jusqu'ici stub).

### Fully Meets — Critère maximal

Note maximale, attribuée quand le contenu satisfait **complètement** l'intention de recherche **sans nécessiter de recherche supplémentaire**. Justifie structurellement les outils interactifs / [[sources/2026-04-12-tim-skills-seo-proprietary]] (skill product-led-seo : calculateur, outil gratuit, maximise le Fully Meets car la réponse est dans la page elle-même). Cf. [[concepts/fully-meets]].

## Limites

- **Pas un algo en production** : QRG ≠ ranking signal direct. C'est une grille d'évaluation humaine qui informe l'entraînement
- **Édition 2026 non vérifiée page par page** dans cette source — Tim cite la p.42 mais le raw ne reproduit pas le passage
- **Subjectivité raters** : les notes restent des évaluations humaines avec variance

## Implications SEO

1. **Contenu IA pur sera pénalisé** (effort-less explicite p.42) — argument normatif fort pour la doctrine anti-IA-pure de Tim
2. **Data propriétaire = avantage E-E-A-T (Experience)** — pas optionnel, c'est dans la grille
3. **Outils interactifs maximisent Fully Meets** — justifie le skill product-led-seo
4. **Autorité se construit hors-page** — LinkedIn, Wikipedia, backlinks (Authoritativeness)
