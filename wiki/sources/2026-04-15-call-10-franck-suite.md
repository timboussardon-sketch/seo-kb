## Doctrine de vente Tim explicitée dans ce call

- **Ne plus vendre du trafic** : vendre des **emails qualifiés / leads** (pas des ventes, car 90-95 % des premiers clics ne convertissent pas) — argumentation que Franck note explicitement
- **Anticiper l'effondrement du clic** lié à AI Mode : "tu pourras pas vendre du clic sur de l'AI Mode, prépare-toi"
- **Dénoncer les "métriques d'agence"** (Top 10, Top 3, nombre de mots-clés) qui cachent les résultats business → "personne ne veut savoir ça"
- **Recommandations programmatique pSEO** sur du local : créer 50 pages avec data ville, **Claude publie via API WordPress / Webflow**, [[concepts/programmatique-pseo]] active
- **Démo Obsidian + Claude Code** : graph view en partage d'écran, setup en 1 week-end (calls clients + concepts + entities). Tim insiste : "Cowork = niveau 0, ça (Claude Code local + Obsidian) = niveau 2"
- **Stack outils Tim révélée** : Claude (90 €) + Grok (recherche data) + ChatGPT (fact-checking). Pas encore Claude 200 €.

## Insights Tim → Franck

- **Désalignement Top-10 vs réservations** sur le client location : top 10 sur longue traîne ne génère pas de leads, mauvais CRO sur les pages locales aggrave le tout
- **Diagnostic** : à 26 ans de SEO, Franck a la data x20 vs Tim → le wiki + Claude Code va exploser ses capacités
- **Mamoot AI vs Claude Code** : Franck utilise Mamoot AI (10 €, accès 15 IA dont Gemini 3 Pro) pour des questions ponctuelles. Tim positionne : "Claude Code = pas un chatbot, un assistant local qui suit tes instructions et garde la mémoire"
