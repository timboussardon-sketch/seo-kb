# Lancer un site de 0 sans CMS

**Newsletter** : Algorithme #2 · **Date** : 4 mars 2026 · **Auteur** : Tim
**URL** : `https://algorithme.substack.com/p/lancer-un-site-de-0-sans-cms`
**Fichier raw** : `raw/articles/algorithme/algorithme-lancer-site-sans-cms.md`

## Données clés

### Test terrain de Tim
- Nouveau domaine, zéro backlinks, zéro historique → **toutes les pages indexées en 3 jours**
- Google a possiblement fait le lien entre LinkedIn, YouTube, Substack → signaux de marque croisés
- PageSpeed bon sans CMS, sans plugin, sans extension

### Thèses opérationnelles
- **SEO = SEO + YouTube + LinkedIn** quand c'est possible → [[concepts/seo-multi-plateforme]]
- **90 % des pages ne sont pas indexées sur Google** → le SEO technique de base reste un filtre binaire
- Ce qui compte : **data propriétaire + prompts propriétaires** = competitive advantage ([[concepts/data-proprietaire]])
- NotebookLM, Gemini, Claude + APIs = système d'agrégation de données pour le contenu
- "Aujourd'hui, ce qui compte, ce n'est pas de savoir rédiger. C'est d'apporter une information que les autres n'ont pas." → [[concepts/surprise-gap]]

### Posture
- "Google a à peine 30 ans. Ce n'est que le début du SEO." — réponse au pessimisme ambiant (GEO va tuer 80% des sites = faux selon Tim)
- "Le SEO est un jeu mathématique. Un jeu à long terme, mais avec une forme de prédictabilité."
