# Premier agent SEO IA : configuration et prompting

**Auteur** : Timothée Boussardon (organikk.co/blog)
**Type** : article
**URL** : https://organikk.co/blog/agent-seo-ia-simple
**Date publication** : 2026-01-28

## Contexte
Framework en trois temps pour configurer Claude en agent SEO spécialisé plutôt qu'en outil généraliste : créer un projet avec instructions custom, ajouter le contexte client, exécuter des prompts d'ingénierie sémantique inversée. Une fois monté, le système est duplicable sur tous les clients.

## Chiffres / faits clés
- Temps de configuration : 10 minutes.
- Méthodologie en 4 étapes : génération, analyse d'intention, clustering, analyse longue traîne.
- 50 mots-clés générés par analyse initiale.
- 3-5 pages piliers recommandées + pages satellites.
- 30 variations pour les mots-clés longue traîne ultra-spécifiques.
- Minimum 3-4 skills pour un agent SEO opérationnel.
- Duplication : 30 minutes par nouveau client.

## Angle SEO à retenir
- Un agent spécialisé (contexte + skills) bat un LLM généraliste ; un agent par client bat une solution multi-clients générique.
- L'ingénierie sémantique inversée maximise le score RRF et vise le « Fully Meets » des Quality Raters, en ciblant transactionnel et micro-niches plutôt que volume.

## Limites
Scrape public complet, pas de paywall. Les repères de temps (10 min config, 30 min duplication) sont des estimations de méthode.
