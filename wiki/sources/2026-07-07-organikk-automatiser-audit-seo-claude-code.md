# Automatiser un audit SEO avec Claude Code

**Auteur** : Timothée Boussardon (organikk.co/blog)
**Type** : article
**URL** : https://organikk.co/blog/automatiser-audit-seo-claude-code/
**Date publication** : 2026-07-07

## Contexte

Méthode pour automatiser des audits SEO mensuels via Claude Code. Le travail du consultant se déplace : il ne produit plus l'analyse, il lit le diff mensuel et prend les décisions. Deux prérequis : de la data Search Console connectée (sinon l'audit IA reste une opinion) et des skills markdown qui rendent les rapports comparables mois après mois. Cas d'étude : [[entities/golfiller]].

## Chiffres / faits clés

- Export [[entities/gsc]] recommandé sur 90 jours
- Cas Golfiller (mars-juin 2026, 90 jours) : 5 480 clics, 113 965 impressions sur le top 1000 requêtes
- Une seule page (tarifs parcours) capture 1 346 requêtes distinctes, dont 388 parcours de golf nommés
- 29 % du trafic vient de requêtes de notoriété
- Cannibalisation détectée : 46 requêtes partagées entre deux calculateurs d'index, 8 588 impressions divisées entre les deux pages
- Exemple de granularité : position 5,9 sur "balle de golf" au singulier vs 15,9 au pluriel
- 4 skills détaillés : indexation (9 points), quick wins, cannibalisation, audit GEO (7 scores)
- Lecture mensuelle du rapport : ~20 minutes ; pipeline pertinent jusqu'à ~1 000 pages

## Angle SEO à retenir

- La valeur n'est pas dans l'audit isolé mais dans le diff : des skills stables rendent les rapports comparables d'un mois sur l'autre, et c'est la comparaison qui produit les décisions
- L'audit IA sans data propriétaire connectée est une opinion — même argument que la doctrine [[concepts/data-proprietaire]] appliqué à l'audit
- Une page qui capture 1 346 requêtes distinctes montre le potentiel des pages à variable ([[concepts/programmatique-pseo]]) mesuré en data réelle
