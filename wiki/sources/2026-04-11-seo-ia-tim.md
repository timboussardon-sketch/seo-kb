## Résumé structuré — Les 4 sections de Tim

### Section 1 — Surprise Metric = nouveau Quality Score

[[entities/titans]] utilise une Neural Memory qui **apprend pendant l'inférence** (test-time memorization). Elle mémorise uniquement les infos à **fort gradient de surprise** — un écart entre ce que le modèle "attend" et ce qu'il "voit".

- **Low surprise** → gradient faible → info non encodée → oubliée.
- **High surprise** → gradient élevé → info gravée dans Neural Memory.

**Conséquence SEO selon Tim** : le contenu IA générique (90% des articles SEO par IA, estimation Tim) a une Surprise Metric ≈ 0. Stratégie : chaque paragraphe doit apporter un **Gradient d'Information** (nouvelle donnée, angle contrarien, expertise unique). Cf. [[concepts/surprise-metric]].

### Section 2 — Biais de récence = nécessité architecturale du Weight Decay

Titans combine **Momentum** (surprise momentanée + passée) et **Weight Decay** (forgetting gate pour ne pas saturer la mémoire). Tim relie ça à l'observation de [[entities/metehan]] : les résultats top 10 sont systématiquement récents de 1-5 ans. **Ce n'est pas un réglage arbitraire** — c'est une contrainte architecturale.

**Conséquence RRF** : inclure un coefficient de "Fraîcheur Sémantique". Contenu ancien → poids s'effondrent via Weight Decay face à du contenu nouveau à fort gradient. Cf. [[concepts/weight-decay]].

### Section 3 — MLE-STAR et les 3 couches de mémoire

Titans structure 3 niveaux :
1. **Core** (Short-term) — attention classique, focus actuel
2. **Neural Memory** (Long-term) — stockage compressé des faits marquants (High Surprise)
3. **Persistent Memory** — connaissances fixes, ne bougent pas

**Pour l'agent SEO MLE-STAR** : ton site doit pénétrer Neural Memory (micro-intentions + surprise forte) **ou** Persistent Memory (marque reconnue → indélogeable). Choix stratégique binaire.

### Section 4 — Synthèse : Ingénierie Sémantique Inversée → Titans/MIRAS

Tim met à jour son framework ([[concepts/ingenierie-semantique-inversee]]) :

| Concept ancien | Évolution Titans | Action SEO |
|---|---|---|
| Vecteurs Sémantiques | Vecteurs de Surprise | Viser la **divergence**, pas juste la pertinence |
| Document Ranking | Neural Memory Entry | High Gradient au **début et à la fin** (primauté/récence) |
| Micro-Intentions | Outlier Handling (YAAD) | Données structurées **impeccables** (prix, dates, stock) |
| Cluster Sémantique | Associative Memory Chain | Chaînes Low Surprise contextuelle + High Surprise informationnelle |

**La thèse finale** : le SEO consiste à apporter l'information manquante — le [[concepts/surprise-gap]] — qui force le modèle à mettre à jour ses poids en temps réel pour inclure ta marque.

## Implications SEO

**Angle 4 nourri avec substance**. Cette source **opérationnalise** l'hypothèse posée sur [[sources/2026-04-11-karpathy-llm-wiki]] ("wiki compilé ↔ Grounding Score") :

- Un wiki persistant qui compound est, du point de vue Titans, un **flux continu d'infos à haut gradient de surprise** — il agrège des claims de plusieurs sources, avec des updates datés et des contradictions flaguées → **plus de signal informationnel** qu'une page statique.
- Chaque page entity du wiki est structurellement une **Associative Memory Chain** (§4 de cette source) — chaque section rappelle les précédentes et ajoute du neuf.
- Le [[concepts/grounding-score]] est maintenant articulé : proximité vectorielle (pertinence) **+ divergence informationnelle** (surprise). Le sweet spot n'est pas la proximité maximale, c'est **grounded et surprenant**.

Cela reste une **hypothèse à tester** — aucune preuve que les moteurs génératifs traitent les pages "style wiki" mieux que les pages statiques. Mais le cadre théorique pour la tester est **en place** dans cette KB.
