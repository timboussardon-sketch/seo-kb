## Contribution

**1. Formalisation GEO** : framework black-box d'optimisation de sites pour maximiser visibilité dans réponses de moteurs génératifs.

**2. [[entities/geo-bench]]** : benchmark 10 000 requêtes, 25 domaines, 9 types de requêtes, 7 datasets sources.

**3. Métriques de visibilité formalisées** : cf. [[concepts/metriques-visibilite-geo]]
- `Imp_wc(c,r)` — Word Count Impression
- `Imp_pos(c,r)` — Position-Adjusted Word Count
- Subjective Impression = 7 sous-métriques LLM-as-judge (G-Eval)

**4. Évaluation empirique de 9 méthodes GEO**.

## Résultats — Table 1 (baseline "No Optimization" = 19.3)

### Méthodes qui marchent

| Méthode | PAWC | Gain vs baseline | Subjective |
|---|---|---|---|
| **Quotation Addition** (citations verbatim) | 27.2 | **+41 %** | 24.7 (+28 %) |
| **Statistics Addition** | 25.9 | +34 % | 24.7 (+28 %) |
| **Fluency Optimization** | 25.1 | +30 % | 24.6 (+27 %) |
| **Cite Sources** (ajout sources) | 24.9 | +29 % | 24.5 (+27 %) |
| Technical Terms | 23.1 | +20 % | 22.7 |
| Easy-to-Understand | 22.2 | +15 % | 22.0 |
| **Authoritative** | 21.8 | **+13 %** (pas 30 %) | 21.3 |

### Méthodes qui ne marchent pas

| Méthode | PAWC | Gain |
|---|---|---|
| Unique Words | 20.7 | +7 % |
| **Keyword Stuffing** | 17.8 | **−8 %** (contreproductif) |

### Combinaison optimale

**Fluency Optimization + Statistics Addition** = **+5.5 %** au-dessus de toute stratégie single.

### Perplexity.ai in the wild — Table 5

- **Statistics Addition** : +9 % PAWC, **+37 %** Subjective (c'est le "+37 %" de l'abstract)
- **Quotation Addition** : **+33 % PAWC** (32.1 vs 24.1)
- **Keyword Stuffing** : −9 % PAWC

## Finding démocratisation — Table 2

Les sites **bas-ranking** gagnent massivement, les sites top-1 **perdent** :

| Méthode | Rank 1 | Rank 5 |
|---|---|---|
| Cite Sources | **−30.3 %** | **+115.1 %** |
| Quotation Addition | −22.9 % | +99.7 % |
| Statistics Addition | −20.6 % | +97.9 % |
| Fluency Opt | −2.0 % | +2.2 % |

**GEO est un levier anti-monopole**. Aligne avec positionnement bootcamp Tim (cible freelance / PME / sites bas-ranking).

## Finding domain-specific — Table 3

Choix de la méthode dépend du **domaine**, pas d'une règle universelle :

- **Law & Gov / Opinion / Debate** → Authoritative, Statistics
- **People & Society / History** → Quotation Addition
- **Facts / Statement** → Cite Sources
- **Business / Science / Health** → Fluency Optimization

## Confirmations normatives

- **Keyword Stuffing −8 % / −9 %** → confirme empiriquement la doctrine [[concepts/anti-ai-writing]]
- **Ajouts chirurgicaux > réécritures complètes** (Table 4 qualitative) → cohérent avec règle "contenu unique" des prompts pSEO

## Limites

- Évaluation 2024 — les GE évoluent vite
- LLM-as-judge (G-Eval) = variance admise par les auteurs
- Top 5 sources seulement par requête (hors top 5 non évalué)
- Single-turn uniquement
- GEO-Bench principalement anglais
