# SEMrush — Taux de conversion du trafic LLM (4x)

## Contexte

Première donnée chiffrée de conversion sur le trafic généré par les LLM (ChatGPT, Perplexity, Gemini) vs Google organique. Pivot argumentatif du discours commercial de Tim sur le bootcamp SEO IA : *"les positions LLM se prennent aujourd'hui, le ROI est exceptionnel"*.

## Méthode

Pas détaillée dans le raw. SEMrush a publié l'étude — méthode propre non vérifiable ici (taille échantillon, secteurs, période, définition "conversion"). À traiter avec confidence medium tant que l'étude n'est pas ingérée en source primaire.

## Chiffres clés

- **4x** : taux de conversion trafic ChatGPT vs Google organique
- **Volume LLM faible** mais conversion "énormissime" (terme rapporté)
- **Confirmation terrain Tim** : ses propres clients voient le même delta de conversion

## Résumé structuré

### Le mécanisme proposé

Les utilisateurs LLM sont **plus tech-savvy** et **plus avancés dans le parcours d'achat**. Quand quelqu'un demande à ChatGPT *"meilleur outil X pour Y"*, l'intention est plus mature qu'une requête Google généraliste — d'où la conversion supérieure.

### Projection business

Quand le volume de recherche LLM augmentera, le ROI deviendra dominant. Argument de positionnement : se placer dans les réponses LLM **maintenant** = avantage durable (analogue à l'early-mover sur Google 2005).

### Connexion doctrine

- Justifie [[concepts/aeo]] (Answer Engine Optimization) comme priorité, pas comme expérimentation
- Renforce [[concepts/data-proprietaire]] : seul le contenu unique est cité par les LLM (cf. [[sources/2026-03-06-algorithme-etude-citation-ia]] +41% citation IA)
- Aligne sur [[concepts/seo-multi-plateforme]] : diversifier au-delà de Google devient un impératif business, pas une option

## Limites

- **Lien étude non fourni** dans le raw — pas vérifiable en l'état
- **"4x"** : ratio sans contexte (4x sur quel secteur ? quelle taille de panier ? quelle attribution ?)
- **Confidence medium** : le chiffre est cohérent avec la confirmation terrain Tim mais isolé tant qu'on n'a pas le rapport SEMrush ingéré
- **Risque de cherry-picking** : SEMrush vend de l'outillage SEO, l'étude pousse mécaniquement leur narratif "investissez dans la SEO LLM"

## Implications SEO

- **Argument de vente bootcamp** : ROI quantifié à brandir en call prospects (ce que Tim fait déjà — cf. raw transcripts à venir)
- **Stratégie requêtes expertes / nichées** : la conversion LLM est portée par les profils avancés → cibler des intentions hautement qualifiées plutôt que volume généraliste
- **À surveiller** : si SEMrush refait l'étude en 2026, comparer le delta — confirmer ou infirmer la projection
