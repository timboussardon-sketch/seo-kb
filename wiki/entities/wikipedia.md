# Wikipedia

Encyclopédie collaborative, première source de citation de plusieurs moteurs génératifs. Illustre le mécanisme [[concepts/geo]] : les LLM citent des sources d'autorité établie plutôt que des sites commerciaux.

## Ce qu'on sait
- Première source citée par ChatGPT, environ 47,9 % des citations relevées [[sources/2026-05-08-organikk-ranker-chatgpt-2026]].
- Chez [[entities/chatgpt-search]] la structure de citation privilégie Wikipedia ; chez [[entities/perplexity]] c'est plutôt [[entities/reddit]] qui domine [[sources/2026-06-02-algorithme-geo-pas-un-scam]].
