# Bootcamp SEO IA (produit Tim)

**Sous-catégorie taxonomique** : Offres/Produits Tim (nouvelle sous-catégorie Entities, §4.1).

Produit commercial phare de Timothée Boussardon / [[entities/fusionn-io]]. Édition #4 : avril-mai 2026. Format 2 phases (1 mois collectif + 1 mois perso), 590€ TTC, 8 participants max.

## Fiche synthétique

| Paramètre | Valeur |
|---|---|
| Prix | 590€ TTC |
| Durée | 2 mois |
| Participants max | 8 |
| Prérequis | Claude 20€/mois |
| CPF / Qualiopi | Non |
| Annulation | Sans frais J-7 |
| Canal | Newsletter Algorithme → call → Stripe |

## Structure

- **Mois 1 collectif** : setup Claude Cowork → rédaction (80/20) → suivi/mesure → contenu LinkedIn + prospection
- **Mois 2 perso** : 1v1 sur cas client réel, création skills personnalisés, workflow sur-mesure livré
