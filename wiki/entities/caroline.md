# Caroline (prospect bootcamp)

**Sous-catégorie taxonomique** : Acteurs / Prospects Bootcamp.

Prospect #13. Employée SEO dans une agence web marketing digital. S'occupe de la partie SEO de manière autonome (pas de manager SEO direct).

## Profil

- Employée agence, pas freelance
- Spécialisée SEO
- Équipe agence avec accès Claude Pro partagés
- Cherche bootcamp pour elle-même avec validation hiérarchique

**Positionnement avatar** : hors des 3 variantes documentées de [[concepts/avatar-freelance-sans-systeme]] (freelance sans système, entrepreneur web, directeur agence). Potentiellement une **nouvelle variante D "employée agence"** à formaliser si d'autres cas similaires arrivent.

## Niveau IA — avancé

Confirmé par Tim en direct (*"j'ai fait pas mal de calls, tout le monde n'en est pas là"*) :

- Claude Projects avec personnalisation
- Création de ses propres "compétences" (skills Claude)
- Combinaison Claude + Gemini pour recherche data
- Audits pré-prod et checks techniques via skills

## Gap à combler (valeur bootcamp)

- Pas de Claude Cowork (reste sur Projects)
- Pas de fichier AGENTS.md / prompt système global
- Pas de base centralisée partageable à l'équipe
- Pas de workflow inter-clients (redémarre par client)

## Question notable

Caroline est la **première** sur 13 calls à demander *"pourquoi Claude uniquement et pas Perplexity / Gemini / ChatGPT ?"*. Sa question mérite une FAQ commerciale dédiée.

## Signal transition freelance

Caroline a mentionné en fin de call : *"à un moment donné, j'aimerais [le freelance], donc ça m'intéresse aussi."* Le bootcamp peut être positionné comme **double-usage** : outiller l'agence à court terme, préparer une transition freelance à moyen terme.

## Statut commercial

- Intérêt : élevé
- Décision : hiérarchique (validation supérieurs nécessaire)
- Prix 590 € TTC annoncé, pas de CPF
- Probabilité conversion : moyenne-haute, point de friction = validation hiérarchie

## Limites factuelles

- Nom de famille non donné
- Nom de l'agence non donné
- Transcription mal nettoyée (typos massives dans le raw)
- Statut final inscription non confirmé à la fin du call
