# YouTube

**Sous-catégorie taxonomique** : Concepts-marque (§4.1 AGENTS.md).

## Ce que cette KB sait

- **48,6 milliards** de visites/mois. 2e site mondial derrière Google.com [[sources/2026-02-27-algorithme-youtube-ai-overviews]]
- AI Overviews citent YouTube dans **~30 % des cas** — avec Reddit et Wikipedia, ce sont les sources les plus citées par les LLMs
- Vidéo = **"preuves atomiques"** multi-vectorielles : texte (transcription), image, son ([[concepts/information-gain]])
- **SEO aujourd'hui = site + YouTube + LinkedIn** selon Tim [[sources/2026-03-04-algorithme-lancer-site-sans-cms]] ([[concepts/seo-multi-plateforme]])
- L'intégration YouTube ↔ Search Console est un signal de ce que Google attend d'un écosystème de sites
- Ultrapersonnalisation (février 2026) : cohérence thématique récompensée, contenu disparate pénalisé (parallèle autorité thématique Google)

## Pertinence SEO/GEO

YouTube n'est pas juste un canal de diffusion vidéo — c'est une **source de données pour les moteurs génératifs**. Être cité par les IA passe par la transcription vidéo structurée, pas seulement le texte web.
