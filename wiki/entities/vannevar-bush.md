# Vannevar Bush

**Sous-catégorie taxonomique** : Acteurs / personnes (historique) (§4.1 AGENTS.md).

Cité dans [[sources/2026-04-11-karpathy-llm-wiki]] comme **ancêtre spirituel** du pattern LLM Wiki via sa vision du **Memex** (1945).

## Le Memex (1945)

Selon la source, le Memex est un *"personal, curated knowledge store with associative trails between documents"*. Une vision de stockage personnel de connaissances :

- **Privé** (vs. public comme le web est devenu)
- **Activement curé** (vs. indexé automatiquement)
- Où **les connexions entre documents sont aussi précieuses que les documents**

[[entities/karpathy]] soutient que la vision de Bush était plus proche du pattern LLM Wiki que de ce qu'est devenu le web public.

## Le chaînon manquant résolu par le LLM

Bush n'avait pas de réponse à un problème clé : **qui fait la maintenance** des trails associatifs ?

> "The part he couldn't solve was who does the maintenance. The LLM handles that"

C'est exactement ce qu'adresse [[concepts/persistent-wiki-vs-rag]] : le LLM prend en charge le bookkeeping que les humains abandonnent faute de temps.
