# SEO multi-plateforme (site + YouTube + LinkedIn)

**Thèse de Tim** : le SEO en 2026 n'est pas juste du site web. C'est un système **site + YouTube + LinkedIn** (quand c'est possible). Le SEO IA est **multi-vectoriel** — une vidéo génère des vecteurs texte, image, son.

## Données clés

- AI Overviews citent [[entities/youtube]] dans **~30 % des cas** [[sources/2026-02-27-algorithme-youtube-ai-overviews]]
- YouTube = 48,6 milliards visites/mois, 2e site mondial
- YouTube + Reddit + Wikipedia = sources les plus citées par les LLMs
- Test Tim : nouveau site indexé en 3 jours — Google a possiblement lié LinkedIn, YouTube, Substack comme signaux de marque [[sources/2026-03-04-algorithme-lancer-site-sans-cms]]
- "SEO aujourd'hui = site + YouTube + article long LinkedIn. 10 meilleurs mots-clés, 1 vidéo par mot-clé."

## Pourquoi ça compte pour le GEO

Les IA cherchent des **preuves tangibles** pour valider leurs réponses. Une vidéo structurée offre des "preuves atomiques" multi-format ([[concepts/information-gain]]). Le [[concepts/grounding-score]] n'est pas que textuel — il intègre des vecteurs image et son via les transcriptions YouTube.

## Implication stratégique

Choisir 10 mots-clés → pour chacun :
1. **Page web** optimisée (data propriétaire, structure Hn, information gain)
2. **Vidéo YouTube** (transcription = texte vectorisable, visuels = preuves)
3. **Post LinkedIn long** (signal social, backlink implicite, brand authority)

Les trois se renforcent mutuellement → signaux croisés de marque → indexation facilitée.
