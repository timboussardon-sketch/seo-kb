Comment faire tourner un agent SEO avec Claude et des skills.

J'ai remplacé une bonne partie de mes outils SEO par un dossier de fichiers markdown.

Chaque fichier est un skill : un process documenté que Claude Code exécute. Mes étapes, mes formats de sortie, mes interdits.

Comment ça tourne, concrètement :

1 skill = 1 process. Le fichier décrit les étapes, le format de sortie et les règles dures. Exemple : jamais de volume inventé, [À SOURCER] quand la donnée manque.

L'agent enchaîne les skills. Recherche de mots-clés → clustering (1 cluster = 1 page) → brief → article. La sortie d'un skill devient l'entrée du suivant.

La matière première, c'est votre data propriétaire : Search Console, calls commerciaux, tickets SAV. Sans elle, l'agent sort le contenu moyen de son corpus. (Et personne ne paie pour la commodité.)

Je le répète depuis des mois : si vous êtes pas bon en SEO, Claude ne sera pas bon. Un skill documente un process que vous maîtrisez déjà.
