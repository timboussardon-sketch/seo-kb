# Sur quels mots-clés tu peux ranker facilement

Les mots-clés faciles ne sont pas les gros volumes : ce sont les sous-niches décisionnelles que les gros acteurs et ChatGPT ne couvrent pas, et les requêtes où ton site sort déjà en page 2.

## Comprendre pourquoi le gros mot-clé n'est jamais le facile
- Le head term est saturé par les gros, annuaires, agrégateurs, agences : un site neuf ne passe même pas le filtre d'admission [[angle-differenciant-mot-cle]]
- Le head term est mangé par ChatGPT, qui répond à la place sur une requête large : zéro clic [[angle-differenciant-mot-cle]]
- L'intention y est floue, donc elle ne convertit pas [[angle-differenciant-mot-cle]]

## Descendre dans l'intention pour trouver le facile
- Descendre du head term vers l'urgence, le moment, le type d'intervention, la micro-zone : à chaque cran la concurrence baisse et l'intention monte [[angle-differenciant-mot-cle]]
- La sous-niche décisionnelle échappe aux gros par construction, car leur SEO est centralisé donc générique [[angle-differenciant-mot-cle]]
- Ces mots-clés se récoltent dans la data propriétaire, calls et SAV, pas dans le Keyword Planner qui ne voit pas le volume trop faible [[angle-differenciant-mot-cle]]

## Garder uniquement les requêtes actionnelles
- Un mot-clé facile ne vaut que s'il est actionnel : l'utilisateur attend une action à la fin, pas juste une lecture [[mots-cles-actionnels]]
- Appliquer le test ChatGPT en deux questions pour éliminer les mots-clés déjà couverts par le LLM [[mots-cles-actionnels]]

## Cibler l'intention Do
- Le mot-clé facile utile est un Do : accomplir une action, format outil, simulateur ou formulaire [[know-simple-know-do]]
- Un Know-Simple répondu à 80 % par ChatGPT ne mérite pas de page, sauf data propriétaire unique [[know-simple-know-do]]

## Ramasser les mots-clés déjà à portée
- Croiser la Search Console pour remonter aux requêtes gagnantes déjà présentes et les scaler sur des pages dédiées [[mots-cles-actionnels]]
- Prioriser ces requêtes déjà classées avant d'en créer de nouvelles [[mots-cles-actionnels]]

## Lancer le diagnostic avec Qadence
- seo-quick-win remonte sur ta Search Console réelle les requêtes où le site est déjà en position 3 à 15, les plus faciles à gagner ; le cron new-opportunity détecte les nouvelles requêtes qui apparaissent en impressions sans page dédiée.
