## 3. Grok + SEO : Pipeline data
**URL :** /blog/grok-seo-pipeline-data
**H1 :** "Grok + SEO : guide avec prompts pour récolter la data de vos articles."

### Pipeline en 7 use cases
- UC0 : Préparer données internes (AVANT Grok) — data propriétaire
- UC1 : Cartographier le consensus (ce qu'il ne faut PAS répéter)
- UC2 : Scanner X DeepSearch 30 jours — chiffres utilisateurs, High Surprise
- UC3 : Stats web < 60 jours — sources primaires (DARES, INSEE, France Compétences)
- UC4 : Croiser pour trouver gaps — ce qui est sur X mais absent de Google = Surprise Gap
- UC5 : Fact-checker chaque donnée (Grok) — ✅ Vérifiée / ⚠️ À nuancer / ❌ Non fiable
- UC6 : Fact-checking complémentaire (Perplexity) — web profond + sources académiques

### Concept central
Surprise Score (mémorisation IA) + Grounding Score (vérifiabilité). Croiser data propriétaire + data externe = contenu inimitable.

## 8. Recherche de mots-clés en 2026
**URL :** /blog/mots-cles-seo-2026
**H1 :** "Mon process complet pour trouver les meilleurs mots-clés SEO en 2026."

### Thèses
- Le volume n'est plus l'indicateur principal
- Mots-clés à zéro volume cachent du business (requêtes 24+ mots)
- Content gaps + vecteurs sémantiques > keyword matching
- Topical authority : 1-5 mots-clés core, 1-20 satellites chacun, ~100 URLs prioritaires

### Workflow
1. Créer bot thématique (Gemini/ChatGPT/NotebookLM)
2. Identifier 1-10 mots-clés core (Google Keyword Planner)
3. Triple validation (Planner + prompts propriétaires + Fusionn)
4. Mapper vecteurs sémantiques et micro-intentions
5. Structurer architecture avant rédaction
