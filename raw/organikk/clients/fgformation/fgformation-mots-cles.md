# RECHERCHE MOTS-CLÉS — Qualiopi / FG Formation (depuis les 14 calls)

> **En résumé.** ~130 requêtes générées depuis la matière terrain, qualifiées par intention ([[concepts/know-simple-know-do|Know-Simple / Know / Do]]) et étage de funnel, organisées par les 9 personas. Aucun volume inventé : tout est `[À SOURCER]` (à brancher sur GSC FG Formation + Ahrefs/[[entities/semrush|Semrush]]). La logique Tim est appliquée : on écarte les têtes génériques (« accompagnement Qualiopi », déjà top 3, plafonné) et on vise les **problématiques** et les **[[concepts/mots-cles-actionnels|requêtes décisionnelles longue traîne]]** où personne ne se positionne. Colonne **Note** = angle de page / point de conversion.
>
> **Difficulté** = proxy déclaratif (nb de mots, présence de têtes génériques, type de SERP attendu), pas une donnée d'outil. À confirmer.
> **Axe** : `F` = formateur indépendant · `OF` = organisme de formation · `T` = transverse. (Rappel : séparer les deux arbres sur le site.)
