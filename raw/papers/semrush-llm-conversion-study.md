# Étude SEMrush : Taux de conversion du trafic LLM

## Référence
- Auteurs : SEMrush
- Date : 2025
- Source : Étude / rapport SEMrush
- Lien : non disponible (cité par Tim dans ses calls prospects)

## Résumé
- Le trafic provenant de ChatGPT convertit **4x plus** que le trafic Google organique
- Le volume de visites LLM reste faible mais le taux de conversion est "énormissime"
- Les profils qui cherchent via les LLM sont plus tech-savvy et plus avancés dans leur parcours d'achat
- Projection : quand le volume de recherche LLM augmentera, le ROI sera exceptionnel
- Confirmation terrain par Tim avec ses propres clients : même constat de conversion élevée

## Concepts clés extraits
- [[aeo]] — Answer Engine Optimization, se positionner dans les réponses LLM
- [[data-proprietaire]] — le contenu unique est celui qui est cité par les LLM
- [[seo-multi-plateforme]] — diversifier au-delà de Google (ChatGPT, Perplexity, Gemini)

## Pertinence pour la KB
Preuve quantitative que le GEO (Generative Engine Optimization) n'est pas théorique mais génère déjà du business. Argument de vente clé pour le bootcamp : "les positions LLM se prennent aujourd'hui". Confirme la stratégie de Tim de se positionner sur des requêtes expertes/nichées plutôt que généralistes.
