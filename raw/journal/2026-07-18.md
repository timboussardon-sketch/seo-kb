# Journal — 2026-07-18

> Entrée écrite à la main depuis la session Claude Code sur organikk-next. Chantier « directories » : sélection, notation, construction, nettoyage voix Tim, déploiement.

## 🎯 Sujets traités

- **Organikk — skill `organikk-directory`** — création d'un skill réutilisable qui trouve, note et construit les pages directory du site. Mode LISTE (génère des idées, passe 5 filtres durs : source publique citable, manque réel en FR, format extractible, assez de matière, audience = prospects ; note /10 = Demande + Différenciation + Conversion − frein de fraîcheur ; si aucune ne passe, ne rien proposer) et mode BUILD (pattern technique exact du repo : fichier de données typé + page index + pages filles + layout DirectoryStyles + sitemap). (organikk-next + ~/.claude/skills)

- **Organikk — 3 modèles proposés puis annulés** — d'abord scorés la fuite de l'API Google Search (9/10), le procès antitrust DOJ (8/10) et le journal des moteurs génératifs (7/10), construits en modèles, puis annulés sur décision de Tim. On est repartis sur d'autres axes. (organikk-next)

- **Organikk — directory « Statuts d'indexation Google »** — `/statuts-indexation-google`, 17 pages (1 index + 16 statuts du rapport GSC : Explorée non indexée, Détectée non indexée, Bloquée par robots.txt, noindex, soft 404, doublons/canonique, 404, 5xx, 401/403, outil de suppression…). Chaque statut : libellé FR + EN officiels, cause, correctif. Source = doc officielle du rapport d'indexation. Notée 9/10 au filtre. (organikk-next)

- **Organikk — directory « Robots des IA »** — `/robots-ia`, 14 pages (1 index + 13 robots et consignes : GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-User, PerplexityBot, Perplexity-User, Google-Extended, Applebot-Extended, CCBot, meta-externalagent, Amazonbot, Bytespider). Chaque robot : nom officiel, respect de robots.txt (partiel/contesté signalé, jamais tranché), rôle, ligne robots.txt pour l'autoriser ou le bloquer. Angle GEO au centre : bloquer l'entraînement n'est pas bloquer la citation. Source = docs des éditeurs. Notée 8/10. (organikk-next)

- **Organikk — guide des évaluateurs, correction traduction** — les requêtes-exemples étaient restées en anglais dans la traduction FR ([ipad reviews], [high definition tv]…). Francisées (174 remplacements), étiquettes Know/Do/Website retirées, « landing page » → « page de destination ». Les noms propres/marques/URLs gardés. (organikk-next, public/qrg-passages.json)

- **Organikk — typo tout Geist** — Tim : « trop de typo différente ». Geist Mono retiré du site entier, `--font-mono` aliasé sur la sans dans globals.css. Une seule police partout (les ~373 usages de mono rendent en Geist). Plus les H1/H2 des directories passés en dégradé bleu Organikk. (organikk-next)

- **Organikk — nettoyage voix Tim sur les directories** — la copie était « full IA writing » : tirets cadratins, antithèses (« ce n'est pas X, c'est Y », « au lieu de »), clichés (« le cœur du sujet »), et du jargon (« jeton », « Googlebot », « Vertex AI », « user-agent », « canonique »). Tout réécrit pour passer le test « un CMO non-SEO comprend en première lecture » : jargon glosé, tutoiement, affirmatif. Règle gravée dans le skill. (organikk-next)

- **Organikk — déploiement** — 3 commits propres poussés sur main (build statuts + typo Geist, build robots-ia, passe voix Tim). 31 nouvelles pages au sitemap. Netlify déploie. (organikk-next)

## 🧠 À retenir

- Le filtre directory marche : sur 15 idées générées, 4 seulement passaient les 5 filtres, et on a rejeté explicitement ce qui doublait une page existante ou obligeait à inventer (brevets Google, lexique GEO déjà dans /glossaire).
- Piège récurrent : la copie technique glisse vite en jargon et en rhétorique IA, même après un premier passage. Le test CMO doit tourner sur les champs de données (cause, fix, detail), pas seulement sur les pages.
- Prochaine directory prête à noter/construire : les codes HTTP pour le SEO et les actions manuelles Google (6/10 chacune), en dessous des deux faites.
