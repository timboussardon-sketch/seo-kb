# Workflow système : installer la machine

**Pré-requis** : skills seo-roadmap-pseo, todo, revue-presse-quotidienne. Un client avec une thématique + une Money Page.

## Le cas

La S4 change la posture : on ne vend pas du trafic, on installe un système que le client garde. Cet exercice met en place les 3 briques : la roadmap, la todo automatique, la revue de presse.

## Ce que tu dois faire

**1. La roadmap**
Lance seo-roadmap-pseo (thématique + Money Page) → calendrier 90j en 2 phases.

**2. La todo automatique**
Installe le skill todo + un cron quotidien avec /schedule.

**3. La revue de presse**
Branche revue-presse-quotidienne sur la thématique du client.

## Ce que tu dois obtenir — le « screen »

```
SYSTÈME INSTALLÉ

1. Roadmap 90j (phase 1 : décisionnel, phase 2 : autorité) + mots-clés rejetés
2. Todo qui se met à jour seule chaque matin (cron)
3. Veille quotidienne sourcée sur la thématique du client

"Voici la machine. Vous la gardez."
```

## Vérifier que tu as réussi

- [ ] Roadmap en 2 phases (décisionnel d'abord) avec section "mots-clés rejetés".
- [ ] Todo qui tourne seule (cron posé).
- [ ] Revue de presse branchée sur le client.
- [ ] Tu peux dire : voici le système que vous gardez.

## Le piège

Vendre des positions. Tu vends un système (temps récupéré + autonomie + actif), pas une promesse de classement.

## Comment ça marche

Les 3 skills s'assemblent en une machine : la roadmap dit quoi faire, la todo suit l'avancement seule, la veille alimente la rédaction. Le client repart avec, c'est ça l'actif.
