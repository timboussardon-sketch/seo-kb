# seo-cluster-aeo : un pilier, 15 pages satellites

**Pré-requis** : le skill seo-cluster-aeo installé. Un mot-clé pilier décisionnel.

## Le cas

À partir d'UN mot-clé pilier (high-intent), tu construis une architecture complète : la page pilier + 15 pages satellites (les spokes), chacune sur une micro-intention, maillées entre elles. C'est ce qui crée l'autorité thématique que les moteurs de réponse citent.

## Ce que tu dois faire

**1. Choisis ton pilier**
Un mot-clé Do, central pour le business. Exemple : "logiciel de facturation".

**2. Lance le skill**

```text
Lance seo-cluster-aeo sur le pilier "logiciel de facturation".
Donne la page pilier + 15 spokes (Know-Simple / Know / Do), chacune avec
sa micro-intention et son maillage vers le pilier.
```

**3. Lis l'architecture**
Chaque spoke = une page, reliée au pilier.

## Ce que tu dois obtenir — le « screen »

```
CLUSTER — logiciel de facturation (pilier)

Know-Simple : c'est quoi un logiciel de facturation
Know        : comment choisir, facture électronique, mentions légales
Do          : logiciel auto-entrepreneur, devis+facture, gratuit,
              meilleur logiciel, alternative à [X], intégration comptable
→ 15 spokes, toutes maillées vers le pilier
```

## Vérifier que tu as réussi

- [ ] 15 spokes minimum, chacune une micro-intention unique.
- [ ] Framework Know-Simple / Know / Do respecté.
- [ ] Chaque spoke maille vers le pilier.
- [ ] Pas deux spokes sur la même intention.

## Le piège

Faire 15 spokes qui répètent le pilier. Chaque spoke doit couvrir une intention que le pilier ne couvre pas.

## Comment ça marche

Le skill décompose l'intention du pilier en sous-intentions MECE (mutuellement exclusives, collectivement exhaustives), lisibles par les agents IA. Chaque spoke capte une requête, toutes pointent vers le pilier qui concentre l'autorité.
