# seo-brief-contenu : le plan de page avant la rédaction

**Pré-requis** : le skill seo-brief-contenu installé. Une requête cible + le contexte client.

## Le cas

Avant de rédiger, tu construis le brief : la structure Hn optimisée pour le Passage Ranking, les micro-intentions à couvrir, le passage ancré. Un bon brief, c'est 80% de l'article.

## Ce que tu dois faire

**1. Donne la requête + le contexte**
La requête cible et ce que tu sais du client.

**2. Lance le skill**

```text
Lance seo-brief-contenu sur "logiciel de facturation auto-entrepreneur".
Structure Hn complète optimisée Passage Ranking, micro-intentions par H2,
un passage ancré 150-200 mots, format multimodal recommandé.
```

**3. Vérifie**
Chaque H2 répond à une micro-intention distincte.

## Ce que tu dois obtenir — le « screen »

```
BRIEF — logiciel de facturation auto-entrepreneur

H1 : ...
H2 : pour qui c'est fait (micro-intention : "est-ce pour moi ?")
H2 : ce qui change vs Excel (micro-intention : "pourquoi changer ?")
H2 : mentions légales gérées (micro-intention : "suis-je en règle ?")
Passage ancré : 150-200 mots dans les 300 premiers. Format : tableau + capture.
```

## Vérifier que tu as réussi

- [ ] Structure Hn complète (H1-H3).
- [ ] Chaque H2 = une micro-intention.
- [ ] Un passage ancré 150-200 mots prévu.
- [ ] Le format multimodal recommandé.

## Le piège

Un plan qui copie les concurrents. Le brief doit prévoir ce qu'ils n'ont PAS dit (le Surprise Gap), pas répéter le top 10.

## Comment ça marche

Le skill décode l'intention, sort les micro-intentions et les ordonne en Hn lisibles par le Passage Ranking. Chaque section devient extractible isolément par les moteurs de réponse.
