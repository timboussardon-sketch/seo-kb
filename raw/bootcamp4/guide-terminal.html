Bootcamp SEO #4 · Organikk

Passer de Cowork à Obsidian + Terminal

1

Récupère ton dossier de travail

Télécharge ton dossier seo-kit depuis ton dashboard bootcamp :
organikk.co/dashboard-bootcamp-organikk-private-2026

Dézippe-le dans Documents pour obtenir Documents/seo-kit. Vérifie qu'à l'intérieur tu as bien les dossiers raw/ wiki/ skills/ et le fichier CLAUDE.md.

2

Installe Obsidian (pour lire tes notes)

Télécharge-le gratuitement sur obsidian.md.

Ouvre-le, puis « Open folder as vault » et choisis ton dossier Documents/seo-kit.

3

Installe Node.js (nécessaire pour le terminal)

Va sur nodejs.org, télécharge la version LTS, installe-la (tu cliques « Suivant » jusqu'au bout).

Pour vérifier, ouvre ton terminal et tape node --version :

terminal — toi
~ % node --version v20.11.1 ~ % # un numéro s'affiche = c'est bon
4

Installe Claude Code

Ouvre ton Terminal — Mac : Spotlight (la loupe) puis « Terminal ». Windows : menu Démarrer puis « PowerShell ».

Colle cette ligne, puis Entrée :

npm install -g @anthropic-ai/claude-code
terminal — toi
~ % npm install -g @anthropic-ai/claude-code added 248 packages in 12s ~ %

Bloqué ? Tu m'envoies un MP.

5

Mets tes skills au bon endroit

Le terminal lit toujours tes skills dans .claude/skills. On y copie ceux du kit. Colle la ligne qui correspond à ton ordi.

🍏 Mac
mkdir -p ~/.claude && cp -R ~/Documents/seo-kit/skills ~/.claude/skills
🪟 Windows (PowerShell)
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null Copy-Item -Recurse -Force "$env:USERPROFILE\Documents\seo-kit\skills" "$env:USERPROFILE\.claude\skills"

Important : la commande n'affiche aucun message quand elle réussit. Pas de message = c'est bon. Vérifie ensuite avec ls ~/.claude/skills :

terminal — toi
~ % ls ~/.claude/skills seo-recherche-mots-cles seo-clustering-mots-cles seo-brief-contenu maillage-systeme seo-mots-cles-decisionnels indexation-check ... ~ %

Le dossier doit s'appeler exactement skills et être dans .claude.

6

Crée le fichier CLAUDE.md (la notice que Claude lit tout seul)

S'il est déjà dans ton kit (vérifié à l'étape 1), tu sautes cette étape.

🍏 Mac — colle ce bloc en entier dans le terminal, puis Entrée

Il crée le fichier au bon endroit, tout seul. Tu colles depuis cat > jusqu'à EOF compris.

cat > ~/Documents/seo-kit/CLAUDE.md << 'EOF' # Méthode de travail : vault raw/ + wiki/ Tu maintiens une base de connaissance personnelle en markdown (pattern « LLM Wiki » de Karpathy). Si les dossiers `raw/` et `wiki/` n'existent pas encore, crée-les. ## Les deux dossiers - `raw/` = mes sources brutes (articles, transcripts de calls, notes, idées). Tu LIS raw/, tu ne le modifies JAMAIS. C'est la source de vérité. - `wiki/` = les notes distillées. C'est TON domaine : tu écris et tu mets à jour ces pages. Moi je les lis, je ne les écris pas. ## Boucle d'ingest (quand je dépose une source et te dis « ingère-la ») 1. Lis la source dans raw/. 2. Résume-moi les points clés. 3. Crée ou mets à jour la page concernée dans wiki/ (résumé, fiche d'entité, concept). 4. Relie les pages avec des wikilinks [[nom-de-page]]. 5. Tiens à jour wiki/index.md (catalogue) et wiki/log.md (journal des ajouts). ## Règles - raw/ est immuable : tu lis, tu n'écris jamais dedans. Tout ce que tu produis va dans wiki/. - Chaque fichier commence par un frontmatter (title, type, date, tags). - Une bonne réponse à une question se classe dans wiki/, elle ne meurt pas dans le chat. Référence : https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f EOF
terminal — toi
~ % cat > ~/Documents/seo-kit/CLAUDE.md << 'EOF' heredoc> # (tu colles tout le bloc, il se remplit ligne par ligne) heredoc> EOF ~ % # fichier CLAUDE.md créé ✓
🪟 Windows — via Obsidian

La commande cat ne marche pas sur PowerShell. Dans Obsidian (déjà ouvert), crée une note à la racine de seo-kit, nomme-la CLAUDE (Obsidian ajoute .md), et colle dedans le même texte que dans le bloc ci-dessus (de # Méthode de travail jusqu'à la ligne Référence :, sans les lignes cat > ni EOF).

Vérifie que CLAUDE.md est bien à la racine de seo-kit (pas dans un sous-dossier).

7

Lance et vérifie

Place-toi dans ton dossier puis lance Claude, et tape /skills :

terminal — seo-kit
~ % cd ~/Documents/seo-kit seo-kit % claude ✳ Claude Code v2.x — dossier : seo-kit > /skills Available skills : seo-recherche-mots-cles seo-clustering-mots-cles seo-brief-contenu maillage-systeme ...

● Tu vois ta liste → tu es opérationnel. Liste vide ? Reprends l'étape 5.

8

Pour relancer une session plus tard

À chaque nouvelle fenêtre de terminal, tu retapes simplement :

terminal — toi
~ % cd ~/Documents/seo-kit seo-kit % claude

Comment ça marche ?

Ton dossier a deux parties : raw/ = tes sources brutes (tu y jettes tout), wiki/ = les notes propres (c'est Claude qui les écrit).

Tu n'as rien à expliquer à Claude : dès que tu lances claude dans seo-kit, il lit tout seul le CLAUDE.md, le mode d'emploi du dossier, et sait déjà comment maintenir raw/ et wiki/.

Cas à part — Google Drive (dossier vu comme « vide »)

Si ton dossier de travail est dans Google Drive et apparaît vide alors que les fichiers sont là : Google Drive en mode « Diffuser / Stream » monte un lecteur virtuel (G:) que le terminal ne sait pas lire. Solution : passe Google Drive en mode « Reproduire / Mirror » (vrai dossier local), ou plus simple, garde ton dossier de travail hors de Google Drive, dans Documents.
