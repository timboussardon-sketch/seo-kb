# Skills SEO à Installer

> Les skills sont les briques de ton système. On les installe progressivement.

---

## Skills de base (Phase 1-2)

### 1. Quick Win
**Quand** : Dès que tu as des données GSC
**Ce qu'il fait** : Identifie les pages en position 3-12 avec impressions élevées et CTR sous-performant
**Input requis** : Export GSC (CSV)
**Statut** : [ ] Installé [ ] Calibré [ ] Testé

### 2. Brief & Structure Hn
**Quand** : Avant chaque rédaction
**Ce qu'il fait** : Produit un brief de contenu avec structure Hn optimisée Passage Ranking
**Input requis** : Mot-clé + intention
**Statut** : [ ] Installé [ ] Calibré [ ] Testé

---

## Skills intermédiaires (Phase 3-4)

### 3. Cannibalisation
**Quand** : Chutes de position inexpliquées, ou avant de publier sur un sujet proche d'une page existante
**Ce qu'il fait** : Détecte et résout les conflits entre pages sur les mêmes requêtes
**Input requis** : Export GSC multi-URLs
**Statut** : [ ] Installé [ ] Calibré [ ] Testé

### 4. Maillage Interne GSC
**Quand** : Architecture sémantique définie
**Ce qu'il fait** : Identifie les opportunités de liens internes à fort ROI via cocon sémantique
**Input requis** : Export GSC + sitemap
**Statut** : [ ] Installé [ ] Calibré [ ] Testé

### 5. Mots-clés Décisionnels
**Quand** : Phase stratégique
**Ce qu'il fait** : Identifie les requêtes à intention business forte depuis la GSC
**Input requis** : Export GSC
**Statut** : [ ] Installé [ ] Calibré [ ] Testé

## Skills avancés (Phase 5-6)

### 6. Score GEO
**Quand** : Optimisation pour les LLMs
**Ce qu'il fait** : Évalue si ton contenu est citable par ChatGPT, Gemini, etc.
**Input requis** : URL ou contenu de la page
**Statut** : [ ] Installé [ ] Calibré [ ] Testé

### 7. Content Gaps
**Quand** : Différenciation vs. concurrence
**Ce qu'il fait** : Identifie ce que les concurrents ne disent pas sur un sujet
**Input requis** : Mot-clé + URLs concurrentes
**Statut** : [ ] Installé [ ] Calibré [ ] Testé
