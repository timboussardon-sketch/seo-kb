# Accompagnement SEO — Espace Client

## Bienvenue

Cet espace contient l'ensemble des ressources de ton accompagnement SEO avec Timothée Boussardon (Organikk).

## Déroulement

**Mois 1-2 : Phase active**
- 1 call hebdo d'1h30
- On construit ton système SEO + IA ensemble
- Tu repars de chaque call avec des actions concrètes

**Mois 3-6 : Phase asynchrone**
- Suivi WhatsApp / email
- Tu m'envoies tes briefs, rédactions, questions stratégiques → je réponds
- On itère sur ton système jusqu'à ce qu'il tourne seul

**À la fin, tu as :**
- Ton workflow SEO complet (identification → rédaction → optimisation)
- Tes skills propriétaires installés dans Claude Cowork
- Ton bot SEO basé sur ton contexte pour continuer après l'accompagnement

## Structure de cet espace

```
📂 00_Admin               → Roadmap, suivi, décisions
📂 01_Stratégie           → MVS, mots-clés, architecture sémantique
📂 02_Système_IA          → Setup Cowork, skills, fichiers contexte
📂 03_Contenu             → Briefs, rédactions, templates de pages
📂 04_Data                → Exports GSC, analyses, quick wins
📂 05_Ressources          → Méthodo, études, références
📂 06_Livrables_Client    → Tes livrables finaux prêts à utiliser
```

## Règles

- Chaque call a un objectif clair → documenté dans le suivi
- Chaque action a un livrable associé → stocké dans le bon dossier
- On ne crée pas de contenu sans brief validé
- On ne brief pas sans données (GSC minimum)
