# Modèles de Pages

> Chaque type de page a sa propre structure. On ne met pas le même contenu partout.

---

## Modèle 1 — Page Service / Offre

**Objectif** : Convertir un visiteur en lead
**Longueur** : 1500-2500 mots
**Structure type** :
```
H1 : [Service] + [bénéfice principal]
  H2 : Le problème que tu rencontres
  H2 : Notre approche / solution
  H2 : Comment ça marche (étapes)
  H2 : Résultats concrets / cas client
  H2 : Pour qui c'est fait
  H2 : FAQ
  CTA : Prendre RDV / Demander un devis
```
**Éléments clés** : Prix si possible (content gap), témoignage, preuve sociale

---

## Modèle 2 — Page Locale / Géolocalisée

**Objectif** : Ranker sur [service] + [ville/zone]
**Longueur** : 1500-2000 mots
**Structure type** :
```
H1 : [Service] à [Ville]
  H2 : Contexte local spécifique
  H2 : Ce qu'on fait à [Ville]
  H2 : Particularités locales
  H2 : Témoignage local
  H2 : FAQ locale
```
**Éléments clés** : Ancrage local précis (noms de quartiers, données locales), pas de contenu générique dupliqué

---

## Modèle 3 — Article Expert / Blog

**Objectif** : Topical authority + trafic middle/top of funnel
**Longueur** : 2000-2500 mots
**Structure type** : cf. template-article.md
**Éléments clés** : Workflow 8 étapes, pattern Tension → Résolution → Preuve

---

## Modèle 4 — Page Comparatif

**Objectif** : Capter l'intention comparative bas de funnel
**Longueur** : 2000-3000 mots
**Structure type** :
```
H1 : [Solution A] vs [Solution B] : [angle unique]
  H2 : Ce que tu cherches vraiment
  H2 : [Critère 1] — Comparaison
  H2 : [Critère 2] — Comparaison
  H2 : [Critère 3] — Comparaison
  H2 : Notre verdict (et pourquoi)
  H2 : FAQ
```
**Éléments clés** : Honnêteté (pas de faux comparatif biaisé), données réelles, prix si possible

---

## Modèle 5 — Glossaire / Définition

**Objectif** : Featured Snippet + topical authority
**Longueur** : 800-1500 mots
**Structure type** :
```
H1 : [Terme] : définition, [angle pratique]
  H2 : Définition simple (passage ancré)
  H2 : Pourquoi c'est important
  H2 : Comment ça marche concrètement
  H2 : Erreurs courantes
  H2 : FAQ
```
**Éléments clés** : Passage ancré optimisé Position 0, liens vers pages filles

---

## Modèle 6 — Page Ressource / Guide

**Objectif** : Page mère du cocon sémantique
**Longueur** : 3000-5000 mots
**Structure type** :
```
H1 : Guide complet : [Thématique]
  H2 : [Sous-thème 1] (→ lien page fille)
  H2 : [Sous-thème 2] (→ lien page fille)
  H2 : [Sous-thème 3] (→ lien page fille)
  H2 : [Sous-thème 4] (→ lien page fille)
  H2 : FAQ transversale
```
**Éléments clés** : Hub central du maillage, chaque H2 renvoie vers une page fille détaillée

---

## Notes
- Chaque modèle est un point de départ, pas un carcan
- Le brief détermine quel modèle utiliser
- Un modèle peut évoluer selon les résultats GSC
