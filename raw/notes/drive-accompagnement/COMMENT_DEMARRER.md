# Comment démarrer avec un client — Guide pratique

> Checklist pour transformer les templates en Drive de travail réel

---

## Avant le Call 1

### 1. Créer le dossier Google Drive client
```
Google Drive → Nouveau dossier
Nom : "Accompagnement SEO [Nom Client] — [Mois/Année]"
```

### 2. Créer les 7 sous-dossiers
- Clique droit dans le dossier → Nouveau dossier
- Crée ces 7 dossiers :
  - `00_Admin`
  - `01_Strategie`
  - `02_Systeme_IA`
  - `03_Contenu`
  - `04_Data`
  - `05_Ressources`
  - `06_Livrables_Client`

### 3. Importer les documents essentiels

Pour chaque fichier `.md` ci-dessous :

**Option A — Manuel (5 min par doc)**
1. Ouvre `/SEO/Drive-Accompagnement/[fichier].md`
2. Copie le contenu entier
3. Crée un Google Doc dans le bon dossier
4. Colle le contenu
5. Formate les titres (H1 = titre principal, H2 = sous-titre, etc.)

**Option B — Bulk (demande-moi)**
Dis-moi : "Crée-moi les .docx pour le Drive" et je génère tous les fichiers en Word. Tu les uploades ensuite.

### 4. Documents à créer AVANT Call 1
```
00_Admin/
  ├── Roadmap accompagnement
  ├── Suivi calls
  └── Decisions log

02_Systeme_IA/
  ├── Setup Cowork
  └── Fichiers contexte template
```

### 5. Partager le Drive avec le client
1. Clic droit sur le dossier racine
2. Partager → Coller l'email du client
3. Donner accès "Éditeur"
4. Envoyer

## FAQ

**Q : Et si le client n'a pas Google Drive ?**
R : Convertis tout en .docx et partage via OneDrive / Dropbox / email.

**Q : Comment importer plusieurs documents à la fois ?**
R : Utilise "Fichier → Importer un fichier" dans Google Docs (fonctionne si tu es en Google Doc).

**Q : Peux-tu convertir les .md en Google Docs d'un coup ?**
R : Je peux créer tous les .docx. Tu les uploades ensuite dans Google Drive.

**Q : Comment modifier un template après l'avoir partagé ?**
R : Crée une version "2.0" du template. Les clients avec l'ancienne version gardent l'accès, mais tu as une version de référence à jour.
