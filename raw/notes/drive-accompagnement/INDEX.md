## Migration vers Google Drive

### Étape 1 — Créer la structure dans Google Drive

Sur Google Drive, crée un dossier racine : **Accompagnement SEO [Nom Client]**

Puis 7 sous-dossiers avec le même nom :
```
Accompagnement SEO [Nom Client]/
  ├── 00_Admin
  ├── 01_Strategie
  ├── 02_Systeme_IA
  ├── 03_Contenu
  ├── 04_Data
  ├── 05_Ressources
  └── 06_Livrables_Client
```

### Étape 2 — Convertir .md → Google Docs

Pour chaque fichier `.md` :

1. **Copier le contenu** (depuis le dossier SEO/Drive-Accompagnement/)
2. **Créer un Google Doc** avec le même nom
3. **Coller** dans le Google Doc
4. **Formater** (titres H1/H2, gras, listes) — Google Docs devrait recognizer la structure
5. **Placer** le doc dans le bon dossier

### Étape 3 — Partager avec le client

Une fois tous les docs créés :
1. Clic droit sur le dossier racine
2. **Partager**
3. Sélectionner "Éditeur" pour que le client puisse modifier
4. Envoyer le lien

## Alternative : Importer en masse

Si tu veux tout importer d'un coup :

1. Télécharge le dossier `Drive-Accompagnement/` sur ton ordi
2. Crée le dossier sur Google Drive
3. Utilise **Google Drive for Desktop** ou **Seafile** pour uploader la structure
4. Convertis les `.md` en Google Docs via "Fichier → Importer un fichier"
