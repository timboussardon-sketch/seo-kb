# Roadmap Accompagnement SEO + Système IA

> Programme en 6 mois — Consultants SEO / Freelances

---

## Phase 1 — Fondations (Semaines 1-2)
**Objectif** : Poser le socle stratégique et le système IA

### SEO
- [ ] Audit de l'existant (GSC, positionnement actuel, architecture)
- [ ] Définir les objectifs business (leads, calls, démos — pas du trafic)
- [ ] Identifier le positionnement de niche vs. généraliste
- [ ] Première extraction GSC + analyse quick wins

### Système IA
- [ ] Setup Claude Cowork (installation, workspace, dossiers)
- [ ] Créer les 3 fichiers contexte (about-me, my-voice, my-rules)
- [ ] Installer les skills SEO de base (Quick Win, Brief Hn)
- [ ] Premier test du workflow sur un cas réel

**Livrable** : Diagnostic initial + environnement Cowork opérationnel

---

## Phase 2 — Stratégie & Identification (Semaines 3-4)
**Objectif** : Construire la stratégie de mots-clés décisionnels

### SEO
- [ ] MVS (Minimal Viable Strategy) : prioriser par horizon temporel
  - 0-3 mois : bas de funnel, micro-intentions business
  - 3-6 mois : middle of funnel + LinkedIn
  - 6-9 mois : topical authority, longue traîne
- [ ] Identification des vecteurs sémantiques (pas des mots-clés isolés)
- [ ] Mapping micro-intentions par cluster
- [ ] Architecture sémantique : pages mères / filles / petites-filles
- [ ] Analyse des content gaps (ce que les concurrents ne disent pas)

### Système IA
- [ ] Installer le skill Maillage Interne GSC
- [ ] Installer le skill Cannibalisation
- [ ] Créer le workflow d'identification des mots-clés décisionnels
- [ ] Automatiser l'extraction et l'analyse GSC

**Livrable** : Carte stratégique complète + skills d'identification installés

---

## Phase 3 — Architecture & Briefs (Semaines 5-6)
**Objectif** : Structurer les pages et produire les premiers briefs

### SEO
- [ ] Définir les modèles de pages (page service, page locale, comparatif, glossaire...)
- [ ] Produire les structures Hn optimisées Passage Ranking
- [ ] Valider les briefs vs. micro-intentions identifiées
- [ ] Maillage interne : cocon sémantique, hiérarchie, PageRank interne

### Système IA
- [ ] Installer le skill Brief & Structure Hn
- [ ] Calibrer le workflow rédaction 8 étapes sur un premier article
- [ ] Tester le chaînage complet : brief → surprise gap → rédaction → article final
- [ ] Itérer sur le ton de voix et les anti-patterns IA

**Livrable** : 3 briefs validés + workflow rédaction calibré

---

## Phase 4 — Production & Différenciation (Semaines 7-8)
**Objectif** : Produire du contenu expert qui se différencie

### SEO
- [ ] Rédaction des premiers articles via le workflow 8 étapes
- [ ] Appliquer le pattern Tension → Résolution → Preuve
- [ ] Intégrer les inversions expertes et l'ancrage local
- [ ] Vérification anti-patterns IA systématique avant publication
- [ ] Optimiser les pages existantes (quick wins identifiés en Phase 1)

### Système IA
- [ ] Installer le skill Score GEO
- [ ] Installer le skill Content Gaps
- [ ] Créer des workflows personnalisés pour le client
  - Workflow veille sectorielle
  - Workflow analyse concurrentielle
  - Workflow reporting automatisé
- [ ] Connecter les MCPs utiles (GSC, Slack, CRM...)

**Livrable** : 3-5 articles publiés + système de production rodé

---

## Phase 5 — GEO & Distribution (Semaines 9-12)
**Objectif** : Optimiser pour les LLMs + distribuer le contenu

### SEO / GEO
- [ ] Audit GEO : le site est-il citable par les LLMs ?
- [ ] Optimiser les blocs d'authorship (extraction Position 0 / AI Overview)
- [ ] Passages ancrés dans les 300 premiers mots (Featured Snippet)
- [ ] Stratégie multicanale : Google, YouTube, LinkedIn, LLMs
- [ ] A/B testing title tags / meta descriptions

### Système IA
- [ ] Créer le workflow de distribution (LinkedIn, newsletter, YouTube)
- [ ] Automatiser le suivi des positions et des citations LLM
- [ ] Installer les MCPs de distribution (réseaux sociaux, email)
- [ ] Créer le workflow de veille automatique (alertes, tendances)

**Livrable** : Stratégie GEO activée + distribution automatisée

---

## Phase 6 — Autonomie & Itération (Mois 3-6, asynchrone)
**Objectif** : Le système tourne seul, on itère

### SEO
- [ ] Suivi mensuel des KPIs (positions, clics, leads)
- [ ] Itération sur les quick wins identifiés par le système
- [ ] Détection et résolution des cannibalisations
- [ ] Nouveaux clusters de contenu basés sur les données GSC

### Système IA
- [ ] Le client produit ses briefs et articles en autonomie
- [ ] Les skills sont calibrés sur son secteur et son ton
- [ ] Les workflows tournent sans intervention
- [ ] Support asynchrone WhatsApp / email pour les questions stratégiques

**Livrable final** : Système SEO + IA complet et autonome
