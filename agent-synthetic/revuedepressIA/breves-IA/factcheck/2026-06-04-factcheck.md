## Détail par claim

### Brève 1 — ChatGPT transforme les marques citées en liens cliquables

**Claim 1.1** : Depuis le 7 mai 2026, ChatGPT affiche les noms de marques comme liens cliquables dans le texte.
- Sources de l'édition : Similarweb + TechnologyChecker → indépendance réelle : le fait qualitatif est corroboré par des observateurs distincts (Search Engine Roundtable, Profound, BrandCited), donc plusieurs sources indépendantes.
- Source primaire : pas de communication OpenAI officielle trouvée. Changement constaté et rapporté par plusieurs acteurs.
- Recherche de contradiction : aucune source ne nie le changement.
- **Verdict : Confirmé** → garder.

**Claim 1.2** : +157,7 % de référents ChatGPT en semaine glissante.
- Sources de l'édition : Similarweb + TechnologyChecker → indépendance réelle : **1 seule**. Le chiffre provient des données clickstream Similarweb (semaine du 7-13 mai vs 30 avril-6 mai). TechnologyChecker republie ce chiffre Similarweb. Search Engine Roundtable l'attribue aussi explicitement à Similarweb.
- Source primaire : Similarweb (relevé d'agence propriétaire, panel clickstream, pas une donnée OpenAI).
- Recherche de contradiction : pas de chiffre concurrent indépendant trouvé ; aucune autre mesure ne reproduit ce relevé.
- **Verdict : Fragile** (mono-source, agrégat d'agence) → garder en attribuant clairement à Similarweb.
- Réécriture proposée : « les référents envoyés par ChatGPT ont augmenté de 157,7 % en une semaine selon les données clickstream Similarweb (panel de sites suivis) ».

**Claim 1.3** : +354,7 % de trafic direct vers les pages d'accueil et domaines racines.
- Sources de l'édition : idem 1.2 → indépendance réelle : **1 seule** (Similarweb).
- **Verdict : Fragile** (même origine unique) → même attribution que 1.2.

### Brève 2 — Gemini 3.5 Flash devient le modèle par défaut d'AI Mode

**Claim 2.1** : Gemini 3.5 Flash devient le modèle par défaut d'AI Mode, mondialement, annoncé à Google I/O 2026, avec interface générative.
- Sources de l'édition : blog.google + TechCrunch → indépendance réelle : **plusieurs** (annonce officielle Google + reprises indépendantes TechCrunch, 9to5Google, MarkTechPost, HotHardware).
- Source primaire : blog.google (officiel Google), relue.
- Recherche de contradiction : aucune source ne conteste l'annonce.
- **Verdict : Confirmé** → garder.

**Claim 2.2** : AI Mode dépasse le milliard d'utilisateurs mensuels, requêtes qui plus que doublent chaque trimestre.
- Sources de l'édition : blog.google → indépendance réelle : 1 (chiffre auto-déclaré par Google).
- Source primaire : Google, relue. Donnée first-party non auditée par un tiers.
- **Verdict : Fragile** (chiffre d'usage auto-déclaré, non vérifiable indépendamment) → garder en attribuant à Google.
- Réécriture proposée : « selon Google, AI Mode dépasse le milliard d'utilisateurs mensuels, avec un volume de requêtes qui plus que double chaque trimestre ».

## Ce que le fact-check a attrapé (le tunnel)

La brève 1 citait « Similarweb + TechnologyChecker » comme deux sources. En remontant, TechnologyChecker ne fait que republier le relevé Similarweb. Recoupement apparent, source unique réelle. Les pourcentages restent publiables, mais comme mesure d'agence attribuée, pas comme fait brut.
