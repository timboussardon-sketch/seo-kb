## Les dernières infos 🍿

**1. Cornell Tech publie l'attaque WARP : 13 mots dans un commentaire UGC déclenchent l'insertion d'entités fictives dans 38 à 51 pct des rapports d'agents de recherche IA**

L'étude « Deep-Research Agents Can Be Poisoned via User-Generated Content » (Zhang, Triedman, Shmatikov) couvre 176 requêtes sur STORM, Co-STORM, OmniThink. Le taux monte à 62 pct dès que l'attaquant manipule plusieurs pages UGC.

*Sources : [Search Engine Land — A 13-word edit can steer what deep-research AI agents recommend (24 juin)](https://searchengineland.com/deep-research-ai-agents-poison-ugc-480952) / [arXiv — Deep-Research Agents Can Be Poisoned via UGC](https://arxiv.org/html/2605.24245v1) / [Help Net Security (23 juin)](https://www.helpnetsecurity.com/2026/06/23/reddit-ai-search-poisoning-research/)*

**2. Albertsons Media Collective et Criteo lancent les Sponsored Products à l'intérieur de la recherche conversationnelle IA, première intégration retailer du genre**

Sur 85 pct des recherches IA Albertsons, l'utilisateur formule une question ouverte ou exploratoire, ce qui place le produit sponsorisé en amont du parcours d'achat. Le format est un carrousel intra-réponse, pas un display sur la SERP du site.

*Sources : [Albertsons Companies Newsroom (23 juin)](https://www.albertsonscompanies.com/newsroom/press-releases/news-details/2026/Albertsons-Media-Collective-Brings-Sponsored-Product-Discovery-to-AI-Powered-Conversational-Search/default.aspx) / [Marketing Dive (23 juin)](https://www.marketingdive.com/news/albertsons-media-collective-criteo-ai-search-brand-ads-ecommerce-omnichannel/823636/) / [Progressive Grocer (23 juin)](https://progressivegrocer.com/albertsons-adds-sponsored-product-discovery-ai-based-conversational-search)*

**3. Salesforce annonce Agentforce Commerce avec trois agents et un branchement direct sur ChatGPT, Gemini et Google AI Mode prévu cet été**

Shopper Agent (B2C, storefronts), Buyer Agent (B2B, WhatsApp et SMS) et Merchant Agent. La connexion catalogue ChatGPT s'opère sans intégration tierce. L'accès Gemini et Google AI Mode est annoncé en rollout pour l'été 2026.

*Sources : [Salesforce — Agentforce Commerce announcement (24 juin)](https://www.salesforce.com/news/stories/agentforce-commerce-announcement/) / [Digital Commerce 360 (24 juin)](https://www.digitalcommerce360.com/2026/06/24/salesforce-releases-ai-agents-b2b-ecommerce-updates/)*

**4. John Mueller précise sur Bluesky comment Search Console compte les impressions dans AI Overviews et AI Mode**

Une impression est déclenchée quand un lien vers une page du site apparaît dans une réponse IA. Si le lien doit être « activé » par l'utilisateur (ouverture d'une carte ou expansion), il n'est compté qu'après activation, ce qui sous-évalue la visibilité observable.

*Sources : [Search Engine Journal — Google's Mueller Explains How AI Search Impressions Get Counted (24 juin)](https://www.searchenginejournal.com/googles-mueller-explains-how-ai-search-impressions-get-counted/580491/) / [Search Engine Roundtable — Google Explains When AI Performance Reports Count Impressions](https://www.seroundtable.com/google-ai-performance-report-count-impressions-41564.html)*

---

**5. John Mueller et Martin Splitt déconseillent dans Search Off the Record les versions markdown parallèles pour LLM**

Le podcast Google rappelle qu'une duplication du contenu en markdown « bot-only » double la charge éditoriale, complique le debug et reproduit les erreurs connues du dynamic rendering. La recommandation est d'améliorer le HTML existant.

*Sources : [Search Engine Journal — Google Cautions Against Markdown Versions Of Websites For AI SEO (23 juin)](https://www.searchenginejournal.com/google-cautions-against-markdown-versions-of-websites-for-ai-seo/580235/) / [Google Search Central — Search Off the Record podcast](https://developers.google.com/search/podcasts/search-off-the-record)*

---

**6. Glenn Gabe documente un site YMYL invisible sur Google mais cité dans ChatGPT, grounding remonté à Bing sur plus de 90 000 prompts**

Le site (contenu généré IA, sans auteur identifié, sans contact) ne ranke plus dans Google après les vagues spam, mais classe sur Bing pour les mêmes requêtes qui le citent dans ChatGPT. Implication directe : Bing Webmaster Tools redevient un signal opérationnel GEO.

*Sources : [GSQI — Surging in ChatGPT, Dead in Google (22 juin)](https://www.gsqi.com/marketing-blog/surging-in-chatgpt-dead-in-google/)*
