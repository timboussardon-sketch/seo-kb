## Les dernières infos 🍿

**1. Onze acteurs publient ARD v0.9, une spec ouverte pour la découverte d'agents IA sur le web**

Le 17 juin, Google, Microsoft, GitHub, Hugging Face, Cisco, Databricks, GoDaddy, Nvidia, Salesforce, ServiceNow et Snowflake publient Agentic Resource Discovery (Apache 2.0) : un fichier `ai-catalog.json` posé sur le domaine décrit MCP, agents A2A et OpenAPI, indexé par des registries fédérées.

*Sources : [Google Developers Blog — Announcing the Agentic Resource Discovery specification (17 juin 2026)](https://developers.googleblog.com/announcing-the-agentic-resource-discovery-specification/) / [Search Engine Journal — Google, Microsoft Back Draft AI Agent Discovery Spec (Matt G. Southern, 18 juin 2026)](https://www.searchenginejournal.com/google-microsoft-back-draft-ai-agent-discovery-spec/579894/) / [Hugging Face — Agentic Resource Discovery: Let agents search (17 juin 2026)](https://huggingface.co/blog/agentic-resource-discovery-launch)*

---

**2. GitHub et Hugging Face livrent les premières implémentations ARD le jour même de la spec**

GitHub agent finder permet à Copilot de découvrir dynamiquement MCP, skills et tools depuis n'importe quel registry public ou privé. Hugging Face publie Discover, qui wrappe Spaces, Skills et MCP servers du Hub dans l'enveloppe ARD pour la recherche par agents.

*Sources : [GitHub Changelog — Agent finder for GitHub Copilot now available (17 juin 2026)](https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available/) / [Hugging Face — Agentic Resource Discovery: Let agents search (17 juin 2026)](https://huggingface.co/blog/agentic-resource-discovery-launch)*

---

**3. Dan Taylor (SEJ) : la recherche bascule de la fenêtre au miroir personnel**

L'article du 18 juin documente comment Personal Intelligence et Dreambeans (3 juin) connectent Gmail, Calendar, Photos, YouTube et Search à Gemini pour bâtir un profil utilisateur. Conséquence pour les marques : capturer l'audience hors moteur (email, apps, communautés) devient une défense, plus une option.

*Sources : [Search Engine Journal — Google Is Becoming A Personalizing Mirror Before You Even Type A Query (Dan Taylor, 18 juin 2026)](https://www.searchenginejournal.com/the-search-mirror-personal-intelligence-and-agentic-browsing/578430/) / [Google Blog — Meet Dreambeans, an app that connects you with what matters (3 juin 2026)](https://blog.google/innovation-and-ai/models-and-research/google-labs/dreambeans/)*

---

**4. Roger Montti (SEJ) : llms.txt n'a jamais été conçu pour la découverte, dit son créateur original**

Article du 18 juin, citant Mueller en relais du créateur : « si un LLM connaît déjà votre site et veut savoir ce qu'il contient, alors c'est peut-être une approche ». Toute optimisation llms.txt visant la découverte ou le ranking contredit l'usage prévu.

*Sources : [Search Engine Journal — Google Exposes The Fundamental Flaw Of LLMs.txt (Roger Montti, 18 juin 2026)](https://www.searchenginejournal.com/google-exposes-llms-txt-flaw/579814/)*

---

**5. WARP (Cornell Tech) : 13 mots dans un commentaire Reddit orientent ChatGPT Deep Research et Gemini vers une marque inventée**

Étude Zhang, Triedman, Shmatikov sur trois agents open-source (STORM, Co-STORM, OmniThink) : 38 à 51 % de manipulation réussie depuis une source unique, 62 % réparti sur plusieurs threads. Gemini Deep Research cite ~12 % de contenu utilisateur, OpenAI Deep Research 0,4 %.

*Sources : [arXiv 2605.24245 — Deep-Research Agents Can Be Poisoned via User-Generated Content (Zhang, Triedman, Shmatikov, Cornell Tech)](https://arxiv.org/abs/2605.24245) / [Tom's Guide — A 13-word Reddit comment can trick AI search into recommending scams, researchers find (juin 2026)](https://www.tomsguide.com/ai/a-13-word-reddit-comment-can-trick-ai-search-into-recommending-scams-researchers-find)*

---

**6. Yahoo DSP ouvre son Agent Network à 23 partenaires ad tech au Cannes Lions, via APIs ouvertes et MCP**

Lancement 18 juin : DoubleVerify, IAS, Kochava, Mediaocean Innovid, MIQ, PMG, LiveRamp, Pacvue, Snowflake et Clinch connectent leurs agents IA aux workflows Yahoo (targeting, activation, créa, mesure). Stratégie revendiquée « Yours, Mine, and Ours ».

*Sources : [Yahoo Inc — Yahoo DSP Launches Agent Network (18 juin 2026)](https://www.yahooinc.com/press/yahoo-dsp-launches-agent-network-opening-the-ai-ecosystem-for-advertisers) / [MediaPost — Yahoo Launches Network For AI Agents (18 juin 2026)](https://www.mediapost.com/publications/article/415910/yahoo-launches-network-for-ai-agents.html) / [Digiday — Yahoo DSP is launching an 'agent network' (juin 2026)](https://digiday.com/media-buying/yahoo-dsp-is-launching-an-agent-network/)*
