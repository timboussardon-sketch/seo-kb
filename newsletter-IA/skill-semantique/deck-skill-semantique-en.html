# Skill — Semantic preparation without SERP

Autonomous engine that produces the complete semantic map of a page to be written (Creation mode) or audits the semantic coverage of existing content (Audit mode). No SERP scraping. The map is built from the query intent, the domain corpus, and the proprietary expertise provided as input.

## Detect the mode

- **Query + profile only** → **CREATION** mode.
- **Query + profile + provided content** (pasted text, file path, or public URL) → **AUDIT** mode.
- If ambiguous, ask: "Do you want to create the semantic map of a page to be written, or audit existing content?"

## Required inputs

### Creation mode

| Variable | Expected value | Status |
|---|---|---|
| Target query | word for word | Required |
| Country / language | EN/US by default | Required |
| B2B/B2C + role | "B2B — CMO, 50-person SaaS" | Required |
| Goal | Lead Gen / Conversion / Expertise | Required |
| Industry | named | Required |
| Audience | junior / expert / mixed | Required |
| Location | city or "N/A" | Required |
| Unique expertise | one signature sentence | Recommended |

### Audit mode (on top of the Creation inputs)

| Variable | Expected value | Status |
|---|---|---|
| Content to audit | pasted text, local path, or public URL (robots.txt OK) | Required |
| Target version | rework / freshness update / expansion / migration | Recommended |

If a required variable is missing, ask **one single grouped question** before producing anything.

## Pipeline — 13 chained phases

```
Phase 0 — Strategic filter (informative, never blocking)
Phase 1 — Micro-intent decoding + Action Engine flag
Phase 2 — Weighted semantic entities (7 columns)
Phase 3 — Signature lexicon (n-grams + co-occurrences)
Phase 4 — Pain points & High-Surprise verbatims
Phase 5 — Quantitative proof (Confidence Score + Freshness Guard)
Phase 6 — Multimodal vectors
Phase 7 — Competitive mapping (5-10 players)
Phase 8 — 3-view Gap analysis (8a Gap Competitive Map / 8b Content Gap Score / 8c Semantic Surprise Score 0-100)
Phase 9 — Calibrated Information Gain divergence
Phase 10 — Strategic FAQ (5-7 latent vectors)
Phase 11 — Structural Information GEO
Phase 12 — Coverage matrix × SERP Triad Mapping
Phase 13 — KB feedback loop (patches to archive)
```

## Detailed format per phase

### Phase 0 — Strategic filter (informative, never blocking)

Three upfront tests. The engine never blocks: it warns and moves on.

**0.1 LLM substitution test** — two binary questions:
1. Does ChatGPT already answer this query at 80%?
2. If yes, can it do better than the user?

Verdict: PASS / WARN / severe WARN ("mandatory divergence" flag in Phase 9 if WARN).

**0.2 Differentiating angle** — is the query a head term typed with 10 different intents by 100 different people (`SEO agency`, `plumber Paris`)? If yes: WARN + suggest sub-niches in an appendix (e.g. `emergency night plumber 15th district`).

**0.3 Vector purity** — ONE dominant intent or several? If several: WARN + suggest splitting into N pages.

Phase 0 deliverable:

```
PHASE 0 — Strategic filter
- LLM test: [PASS / WARN — reason]
- Differentiating angle: [PASS / WARN — suggested sub-niches: (1) ... (2) ...]
- Vector purity: [PASS / WARN — N intents: (1) ... (2) ...]
Overall verdict: [clear GO / GO with warning]
```

The engine always continues to Phase 1.

### Phase 1 — Micro-intent decoding + Action Engine flag

Three levels of intent:
- **Main intent**: Know-Simple / Know / Do taxonomy (replaces TOFU/MOFU/BOFU)
- **Sub-intents**: 3 to 5 parallel questions
- **Micro-intents**: 15 to 25 granular questions

User profile reformulated in one sharp sentence.

**Action Engine flag**: if the main intent = `Do`, the flag is mandatory — an interactive tool (calculator, simulator, generator, audit) is required to target Fully Meets. A text-only Know page does not rank on a Do intent.

### Phase 2 — Weighted semantic entities (mandatory 7-column format)

30 to 50+ entities per run. Strict format:

```
| # | Entity | Type | Weight (0-1) | Target density (%) | Estimated cosine to query (0-1) | Justification | Status |
|---|---|---|---|---|---|---|---|
| 1 | `passage ranking` | Concept | 0.94 | 0.8% | 0.91 | Grounding building block, cited in 3 MIRAS papers | P1 critical |
| 2 | `BM25` | Algo | 0.87 | 0.3% | 0.79 | Underlying mechanics of Document Ranking | P1 critical |
```

- **Type**: Person / Concept / Tool / Method / Doctrine / Event / Location / Algo
- **Weight**: > 0.8 = pivot entity, 0.5-0.8 = supportive, < 0.5 = peripheral
- **Target density**: pivots 0.5-1%, supportive 0.2-0.5%, peripheral < 0.2% (per 2,000 words)
- **Estimated cosine**: Claude's projection of entity ↔ query similarity, **marked "simulated"** in the table footer
- **Mandatory justification**: short (paper, doctrine, co-occurrence). No arbitrary entity.
- **Status**: P1 critical (without it, no ranking) / P2 (supportive) / P3 (bonus)

Mandatory table footer: *"Cosine simulated by Claude corpus projection, not mathematically calibrated. For exact calibration: Voyage / Cohere / OpenAI embeddings API."*

### Phase 3 — Signature lexicon (n-grams + co-occurrences)

```
| N-gram / expression | Type | Expected frequency (per 2,000 words) | Dominant co-occurrence | Status |
|---|---|---|---|---|
| "grounded passage" | bigram | 2-3x | grounding-score, featured snippet | P1 |
| "ranking in ChatGPT" | trigram | 1-2x | AIO, LLM citation | P1 |
```

Bigrams (2 words), trigrams (3 words), multi-word expressions (> 3). Dominant co-occurrence = which other entities/concepts this n-gram systematically appears with. Status P1 = domain standard / P2 = signature bonus.

### Phase 4 — Pain points & High-Surprise verbatims

Table of at least 10 rows:

```
| Micro-intent / Pain point | "High-Surprise" verbatim | Expected atomic proof |
|---|---|---|
| [Named, precise blocker] | [Expert quote rarely verbalized — zero cliché] | [Subject + Verb + Quantified data point] |
```

**Verbatim rules**:
- Expert or technical frustration specific to the trade
- Signature vocabulary (locked to the profile's B2B/B2C)
- Strict refusal of clichés ("I want ROI", "I want results")

Example:
- ❌ Cliché: "I want to see concrete results"
- ✅ High-Surprise: "The last agency sent me 40-page reports where the only readable KPI was the number of backlinks, never crossed with my CRM"

**Atomic proof rules**: binary or quantified format, verifiable.
- ✅ "73% of B2B prospects turn down a quote without an instant estimate"
- ❌ "We provide excellent service"

**Final prioritization**: output 3 critical objections ranked by `frequency × intensity × differentiation`.

### Phase 5 — Quantitative proof (Confidence Score + Freshness Guard)

Generated from training: dated figures with a primary source, studies, papers, case law, field cases.

**Confidence Score per proof**:

| Level | Criterion | Action |
|---|---|---|
| High | Recent primary source identified, paper with DOI, official body | Usable as is |
| Medium | Known source but not 100% verified | Usable + mandatory downstream fact-check |
| Low | Indirect rewording, secondary source, approximate data | **Replace with `[TO SOURCE]`** |

**Absolute rule**: if confidence is low or the source unknown → mandatory `[TO SOURCE]` placeholder. No invented number.

**Freshness Guard**:

| Data age | Status |
|---|---|
| < 18 months | Fresh proof — OK |
| 18-36 months | "To refresh" flag — usable but flagged |
| > 36 months | Omitted except foundational papers (structural, non-substitutable studies) |

Deliverable format: proof + source + confidence + dating + freshness flag + covered micro-intent.

### Phase 6 — Multimodal vectors

Tables, diagrams, screenshots, photos, short videos, audio, interactive data. For each: semantic goal + format + covered micro-intent.

### Phase 7 — Competitive mapping without SERP

5 to 10 dominant players identified from: Claude training + targeted WebSearch (robots.txt OK) + internal KB if provided.

```
| Player | Type | Dominant angle | Identifiable weakness |
|---|---|---|---|
```

Type: media / agency / individual expert / institution / platform. Dominant angle = the thesis they defend. Weakness = what they don't cover, don't say, or refuse to see.

### Phase 8 — Gap analysis (3 views)

**8a. Gap Competitive Map** — player × concept matrix (P1 critical entities only, otherwise too dense):

```
| Player | Entity A | Entity B | Entity C | Entity D | Entity E | Exploitable gap |
|---|---|---|---|---|---|---|
| Player X | ✅ | ✅ | ❌ | ✅ | ❌ | Entities C + E |
| **MARKET GAP** | — | — | — | — | **0/3** | **E = general gap** |
```

An entity with a shared gap (never covered by the 3 analyzed players) = a priority attack opportunity.

**8b. Content Gap Score**:

| Axis | Definition | Target |
|---|---|---|
| Standard coverage | % of P1 entities that 80%+ of competitors cover | ≥ 70% (pass Document Ranking) |
| Surprise coverage | % of P1 entities covered by < 20% of competitors | ≥ 30% (pass Information Gain) |

Verdict:
- Standard < 70% → the page lacks the semantic base, it does not rank
- Standard ≥ 70% but Surprise < 30% → indexable but Low Surprise, forgotten by AI models
- Standard ≥ 70% AND Surprise ≥ 30% → ideal target

**8c. Semantic Surprise Score 0-100** — weighted average of 4 components:

```
30% — Ratio of proprietary entities / total entities
20% — Ratio of High-Surprise verbatims / total verbatims
25% — Proprietary ↔ consensus lexical distance (1 - simulated cosine)
25% — Presence of Quotation Addition + Statistics Addition (verbatim + sourced quantified proof)
```

Scale:
- **0-30** = Statistical mediocrity (guaranteed memory oblivion, rework or abandon)
- **30-60** = Acceptable but replicable (mandatory P1 improvements)
- **60-85** = Information Gain validated (OK to publish)
- **85-100** = Maximum expert inversion

Mandatory warning: *"Score calibrated on Claude corpus projection. For exact calibration: GEO audit with algorithmic scores."*

### Phase 9 — Calibrated Information Gain divergence

Aggarwal KDD'24 benchmark (arXiv:2311.09735) — PAWC gains measured vs baseline:

| Method | PAWC gain |
|---|---|
| Quotation Addition (verbatim quote) | +41% |
| Statistics Addition | +34% |
| Cite Sources | +29% |
| Authoritative (tone alone) | +13% |

Favor divergent angles backed by **verbatim quotes + sourced statistics**, not by authoritative tone.

For each divergence axis, require:
- Targeted dominant player (from Phase 7)
- Attacked entity from the Gap Competitive Map (Phase 8a)
- Type of inversion (lazy vs true-but-counterintuitive)
- Form (verbatim quote, proprietary stat, field case, sourced external data)

Final criterion: an expert would say *"huh, I had never seen it that way"*.

### Phase 10 — Strategic FAQ (5-7 latent vectors)

5 to 7 questions = 5 to 7 distinct semantic vectors. Zero overlap with the body.

Strict rules:
- Each question answers a micro-intent **not covered by the body**
- Short, actionable answer, quotable in isolation (AI Overview ready)
- B2B/B2C lock according to the Phase 1 profile
- No generic educational question ("what is X")
- Priority to Know / Comparative / Do questions not covered in the body

The FAQ absorbs the semantic periphery to preserve the body's vector purity.

### Phase 11 — Structural Information GEO

SAGEO Arena 2025 finding (Kim et al., Yonsei, arXiv:2602.12187): optimizing the body alone **degrades** retrieval (−4.54 Hit Rate). Structural optimization brings +22% Hit Rate. Structural + Statistics combined: **+35%**.

```
| Field | Semantic constraint | Entity(ies) to include (Phase 2) |
|---|---|---|
| Title (≈10 words) | Exact keyword + differentiator | Main entity + divergence angle |
| Meta description (155 char) | Answer-first + measurable benefit | Main entity + action verb |
| H1 | Semantic keyword + promise | Main entity + Surprise Gap |
| H2 (5-8 planned) | Each H2 = one distinct semantic vector | One entity or concept per H2 |
| Schema.org | Type matched to the intent | Article + FAQPage + LocalBusiness (if geo) + HowTo (if Do) + VideoObject (if multimodal) |
```

### Phase 12 — Coverage matrix × SERP Triad Mapping

Crosses micro-intents × layers from Phases 2-11. Verifies that no micro-intent is orphaned.

**SERP Triad Mapping** — each deliverable is tagged with the Google phase it feeds:

```
| Produced layer | Target SERP Triad phase | Mechanism |
|---|---|---|
| Named entities + Structural Information | Phase 1 — Document Ranking (admission) | BM25 + RankBrain |
| Structuring concepts + proof + grounding + n-grams | Phase 2 — Passage Ranking (per-block density) | DPR / Muvera + BERT |
| FAQ + answer-first + Surprise Gap | Phase 3 — Generation (AIO, LLM citation) | Grounding + Confidence Score |
```

Without this mapping, the downstream writer does not know where to place what.

### Phase 13 — KB feedback loop

At the end of each run, identify the elements to version into the local KB (if the user has one):

```
Add to /concepts/: concept-X.md (one-sentence summary)
Add to /entities/: entity-Y.md (role in the domain)
Add to /competitors/: competitor-Z.md (angle + weakness)
Add to doctrine.md: doctrine-W (sharp formulation)
Archive in /verbatims/: verbatim-V.md (rare expert frustration)
Archive in /lexicon/: n-gram-N.md (signature expression)
```

The user validates or adjusts before archiving. Without this phase, the engine does not improve — with it, it self-improves on every run. If the user has no structured KB, simply list the candidate elements so they can copy them wherever they want.

## Absolute rules

- **No SERP scraping**, ever. Not Google, not Bing, not any other engine.
- **Strict robots.txt** for any WebFetch. If blocked: Claude training + ask the user, never bypass.
- **Simulated cosine always marked**: Phase 2 + Phase 8c outputs carry the "simulated by Claude corpus projection" warning.
- **Mandatory Confidence Score** on every quantified proof. If low or unknown → `[TO SOURCE]`. No invented number.
- **Freshness Guard**: proof older than 36 months omitted except foundational papers.
- **Phase 0 never blocks**: WARN alert + sub-niches in appendix, always produces the full map.
- **No copywriting**: no final H1, no hook, no final Hn architecture, no CTA, no narrative prose.
- **One page = one intent** (vector purity). If Phase 0.3 finds multiple intents → WARN + N sub-maps in appendix.
- **Mandatory anti-cliché** in Phase 4: no "I want ROI", no "I want results".
- **Phase 2 — Mandatory justification**: every entity comes with its short justification. No arbitrary entity.

## Concepts used (inline definitions — for standalone use)

- **SERP Triad**: the 3 successive phases a query goes through on modern Google — Document Ranking (admission filter via BM25/RankBrain), Passage Ranking (per-block semantic density via DPR/Muvera/BERT), Generation (citation in AI Overview / Featured Snippet / LLM answer).
- **Information Gain**: a Google standard formalized in the Quality Rater Guidelines (page 42) — effortless content that repeats what already exists gets the lowest rating. The Aggarwal KDD'24 benchmark (arXiv:2311.09735) measures the methods that raise IG.
- **Confidence Score**: reliability level of a quantified proof (high / medium / low) that determines whether it is usable as is, to fact-check, or to replace with `[TO SOURCE]`.
- **Freshness Guard**: proof-age rule — < 18 months fresh, 18-36 months flagged, > 36 months omitted (except structural foundational papers).
- **Action Engine flag**: flag raised in Phase 1 when the intent is `Do` — the page must then embed an interactive tool (calculator, simulator, generator, audit) to target the Quality Raters' Fully Meets rating.
- **Vector purity**: one page = one intent. Multiple intents dilute the semantic vector and push the page out of retrieval.
- **Answer-first pattern**: the direct answer must sit at the top of the section/page, not after 800 words of context. Validated by the Positional Bias finding on LLM rerankers (arXiv:2604.03642).
- **Grounding Score**: measure of fidelity to sources — a priority sorting criterion for modern LLMs, more important than keyword stuffing.
- **Know-Simple / Know / Do**: intent taxonomy that replaces TOFU/MOFU/BOFU for the LLM era. Know-Simple = isolated fact, Know = full understanding, Do = transactional action.
- **Surprise Gap**: the fracture between what all competitors say (consensus) and what only you say (proprietary angle). The wider the gap, the better AI models memorize the content.
- **Structural Information GEO**: SAGEO Arena 2025 finding (Kim et al., arXiv:2602.12187) — optimizing the body alone degrades retrieval; optimizing the structural layer (title, meta, headings, schema) + adding sourced statistics brings +35% Hit Rate.

## Audit mode — differences

In Audit mode, every phase produces **3 columns** instead of one: Expected (computed as in Creation mode) / Covered in the current content / Gap + corrective action.

Three statuses per layer:
- ✅ Covered: expected element present and compliant → validation
- ❌ Gap: expected element missing or non-compliant → correction to plan
- ⚠️ Out of scope: present element that matches no expected layer → remove or relocate (FAQ, another page)

The "Out of scope" status is critical: it preserves vector purity.

**Prioritized correction plan** delivered at the end:

```
CORRECTION PLAN — Content: "[title/URL/path]"
Current Semantic Surprise Score: XX/100 — [verdict]

P0 — Blockers (fix before publishing)
- [Phase X — Layer Y] Gap: [description] → Action: [verb + precise object]

P1 — Important (before the next update wave)
- [...]

P2 — Improvements (on following versions)
- [...]

OUT-OF-SCOPE ELEMENTS detected:
- [Quote from the content] → Reason: pollutes the vector → Action: relocate / remove

Overall coverage score: X/11 layers covered
```

- **P0**: Gap on Phase 11 (Structural) or a whole SERP Triad phase uncovered → the page does not pass Google's admission
- **P1**: Gap on Phase 4 (pain points), Phase 9 (divergence), Phase 5 (proof), or Surprise Score < 60 → indexed but Low Surprise
- **P2**: Gap on Phase 10 (FAQ), Phase 6 (multimodal), Phase 13 (KB patches) → ranks but does not maximize SERP Triad phase 3
