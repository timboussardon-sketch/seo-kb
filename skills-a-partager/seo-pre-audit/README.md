# Skill : seo-pre-audit (à partager)

Skill autonome qui prépare un pré-audit SEO/GEO d'un prospect ou client AVANT un call, à partir de sa seule URL et de données 100% publiques. Aucun outil payant, aucune Google Search Console requise.

## Installation (côté élève)

```bash
mkdir -p ~/.claude/skills/seo-pre-audit
cp SKILL.md ~/.claude/skills/seo-pre-audit/SKILL.md
```

## Utilisation

Déclencher dans Claude avec : « fais un pré-audit sur [URL] » ou « prépare le pré-call sur [site] ».

Le skill déroule 3 phases : collecte (publique), grille des 7 insights business, puis squelette de sortie complet (résumé, diagnostic, angle, état SEO, pSEO multi-axes, roadmap 90 jours, notes de call).

Règle dure intégrée : aucun volume, position ou trafic inventé.
